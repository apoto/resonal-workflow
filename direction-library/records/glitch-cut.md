# グリッチカット / Glitch Cut

## 概要
カット点に2〜6フレームのデジタルノイズ（RGB分離・ブロックノイズ・走査線・フレーム崩れ）を挟んで場面転換するカット。「データとして壊れた」質感が狂気・混乱・攻撃性を運ぶ、ボカロ/EDM系MVの基本語彙。転換とアクセントの両方に使える。

## 主な用途
- ボカロ/EDMの場面転換（世界観がサイバー/病み系なら第一候補）
- ビルドアップ終盤のスタッター（音の連打と映像の乱れを同期）
- 精神崩壊・記憶の混濁・二重人格の表現（物語装置として）
- リリックビデオの文字化け演出（歌詞が壊れて次の歌詞になる）
- AI生成素材の破綻フレーム隠し（実用技）

## 難易度
★2（AEの標準機能で作れる。ffmpegなら1行。ただし「音と合っていないグリッチ」は事故にしか見えないため同期設計は必須）

## 使用頻度
A — 全ジャンルではA、ボカロ/EDM/サイバー系ではSに繰り上がる。サイバー系では常備品。

## 使用タイミング
- ビルドアップ終盤2〜4小節（スタッター連打）
- Drop頭（smash-cutの変化球として）
- 2番Aメロ頭（1番と同じ構成に「壊れ」を足して差分を作る）
- 間奏（世界が崩れて心象風景へ）
- サビ中のアクセント（2拍に1回の軽グリッチでグルーヴ補強）

## 演出内容
- **基本:** カット点に2〜6フレーム（24fpsで83〜250ms）のノイズフレームを挟んでA→Bへ転換。**長いと「エフェクトの見せびらかし」になり転換機能が死ぬ。** 迷ったら3フレーム
- **ノイズの内訳（重ねるほど強い）:** RGB分離（ずれ幅4〜20px）／ブロックノイズ（8〜32pxグリッド）／走査線・スキャンライン／フレームホールド＋帯状ずらし／ピクセルソート
- **音との1:1対応が絶対条件。** スタッター、ビットクラッシュ、リバースシンバル等のSEとフレーム単位で同期させる。音のないグリッチは再生事故に見える
- **2用途を区別する:** ①転換（カット点を汚してA→B）②アクセント（同一カット内で一瞬乱れて戻る）。①は3〜6フレーム、②は1〜3フレームと短めに
- **実写:** 完全に後付け（撮影段階ですることはない）。素材のエッジがはっきりした画ほどノイズが映える
- **アニメ/イラスト:** 後付けに加えて「作画グリッチ」が独自にできる——色トレス分離、セル抜き（塗りだけ消えて線画が残る）、パーツ差し替えの1コマ挿入。デジタル破壊ではなく「絵として壊れる」のはこの媒体だけ
- **3DCG:** 頂点シェーダ破壊・テクスチャUV崩し・Zファイト風チラつきで「3Dデータそのものが壊れた」説得力が出る。ポストのノイズより一段深い壊れ方

## カメラワーク
- なし（編集演出）。素材側は固定〜微揺れが基本
- handheldの微シェイクとは好相性（不安定さの二重奏）。大揺れとの併用は酔う

## 編集
- 本演出そのもの
- smash-cutのカット点に足す「汚し」としての運用が最頻出
- フレームホールド（1フレーム静止）→ノイズ→復帰の「引っかかり」はスタッター音と完全一致させる

## 色
- **メインカラー:** 黒背景＋原色ノイズ（シアン/マゼンタ/緑）がデジタル破損の記号
- **アクセントカラー:** RGB分離の赤/青ずれ。白フレームを1枚混ぜると点滅感が加わる
- **相性の良い配色:** ネオン系パレットとは同族。逆にパステル/フィルム調の画にグリッチを乗せると「世界観の侵食」という物語になる

## ライティング
- Neon: サイバー世界観の光源として同族
- 走査線・モニター光（画面前の顔をブルーライトで照らす）はグリッチの「発生源」の説明になる
- Strobe: グリッチ点滅と同期させると照明・編集の二段構えになる

## リリックとの相性
★★★★★ — 文字化け（歌詞の一部が■や乱数に置き換わる→正しい文字に復元）、字形の分解・RGBずれはリリックビデオのグリッチ表現として王道。kinetic-typographyとの組み合わせはボカロMVの定番中の定番。文字は画よりグリッチ耐性が高い（読めなくなる寸前が一番かっこいい）。

## AI画像生成で再現する場合
静止画では「グリッチのかかった1枚」を直接生成できる。
- **共通キーワード:** glitch art, chromatic aberration, RGB split, scanlines, corrupted data, databending, pixel sorting
- **画像生成（providers.image）:** 「the image looks like corrupted digital data, horizontal displacement bands, RGB channels separated」と現象を文章で列挙する。人物の顔は崩れすぎるので、グリッチは弱めに書くか顔以外に限定する

## AI動画生成で再現する場合
**グリッチは100%編集工程。生成AIに「glitch」と頼むより後処理の方が制御できる。**
- **素材生成の注意:**
  - 転換用途では**前後カットの色相を意図的に離す**（色が近いとノイズを挟んでも場面が変わったと伝わらない）
  - グリッチを乗せるフレームは動きの大きい瞬間が自然（静止画に突然ノイズが走ると合成感が出る）
  - **生成AIの破綻フレーム（溶け・モーフ崩れ）は天然のグリッチ素材。** 捨てテイクから採取してカット点に1〜2フレーム挟むと、作り物でない崩れ方になる
- **After Effects:** ①チャンネルシフトでRGB分離 ②フラクタルノイズをマップにしたディスプレイスメントで帯状ずらし ③タイムディスプレイスメントで走査線状の時間ずれ——の3点セット。調整レイヤーに乗せてカット点の3フレームだけ有効化
- **Premiere:** 標準ならVRデジタルグリッチ（イマーシブビデオ用だが平面素材にも使える）。本格運用は市販のグリッチ系プラグイン
- **ffmpeg:** RGBずらしを3.0〜3.15秒だけ有効化する簡易例:
  ```
  ffmpeg -i in.mp4 -vf "rgbashift=rh=-12:bh=12:enable='between(t,3.0,3.15)'" out.mp4
  ```

## 類似演出
- datamosh（Pフレーム破壊で溶かす。グリッチの重加工版）
- rgb-split（グリッチの構成要素を単体で使う演出）
- flash-cut（単色コマ挿入。ノイズコマ挿入と構造が同じ）
- smash-cut（カット点の急転換という骨格が共通）

## 相性の良い演出
- rgb-split（グリッチの瞬間以外にも常時薄く敷いて世界観を統一）
- datamosh（グリッチカットの最上級形として要所で）
- neon-lighting（サイバー世界観の光源として同族）
- flash-cut（ノイズフレームに白1コマを混ぜて点滅感を追加）
- smash-cut（カット点の汚しとして直乗せ）
- speed-ramp（変速点にグリッチを置いてデジタルな解釈に）
- camera-shake（微シェイクと重ねて不安定さを二重に）
- kinetic-typography（文字化け演出。ボカロMVの王道コンボ）
- color-shift（グリッチの瞬間に色相が変わる=壊れて世界が変色）
- zoom-punch（衝撃系アクセント同士、交互に使うと単調回避）

## 相性の悪い演出
- light-leak — アナログの柔らかい光とデジタル破壊は質感の出自が正反対。世界観が割れる
- lens-flare — 同上。オーガニックな光学現象はグリッチのシャープさを鈍らせる
- match-cut — 一致の視認をノイズが遮る。マッチカットの意味が消える
- push-in（超スロー）— じわじわ寄る連続性を数フレームの乱れが断ち切る（push-in側の記述と対応）

## 注意点
- **音と同期していないグリッチは再生事故に見える。** 必ずSE（スタッター/ビットクラッシュ）とフレーム単位で対応させる
- 6フレームを超えるとトランジションではなく「エフェクト鑑賞」になる。転換用途は3フレーム基準で切り詰める
- 常時グリッチは3秒で飽きる。**平常時が綺麗なほど壊れた瞬間が効く**——密度配分を先に決める
- プラグインのプリセット一発は既視感が強い。RGBずれ幅・ブロックサイズ・タイミングの3つは必ず手で調整する
- 世界観の合意が要る。オーガニック/生楽器/フィルム調の曲に置くなら「侵食される物語」として理由を作ること

## バリエーション
- **転換グリッチ:** カット点に3〜6フレーム。A→Bの場面転換の標準形
- **スタッターグリッチ:** フレームホールド＋ずらしを音の連打と同期。ビルドアップ終盤専用
- **軽グリッチ:** RGB分離のみ1〜2フレーム。サビ中のアクセントとして2拍に1回
- **作画グリッチ:** アニメ/イラスト限定。線画と塗りの分離・色トレス崩し・1コマ差し替え
- **ホールドグリッチ:** 1フレーム静止→ブロックノイズ→復帰。「引っかかってから壊れる」時間差
- **ワイプグリッチ:** ノイズ帯が画面を縦/横断し、通過した部分から次のカットに置き換わる
