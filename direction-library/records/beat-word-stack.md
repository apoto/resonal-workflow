# ビート同期ワードスタック / Beat-synced Word Stack

## 概要
1拍＝1ワード（文節）を画面に「着地」させ、**既出ワードを消さずに残して群れを育てる**加算型リリック演出。フレーズ終端で群れごと一掃し、次のフレーズを新しい空白から積み直す。サビの歌詞を「読む」から「浴びる」に変える。

## 主な用途
- サビ/ドロップの歌詞を高密度・高エネルギーで見せる
- 静かなAメロ（小さな中央1行）との落差でサビの爆発を作る
- ラスサビで素材だけ差し替えて再登場させる（エスカレーション）

## 感情
- 高揚 / 疾走 / 多幸感 / 熱狂 / 決意 / 挑発 / 解放

## 演出カテゴリ
- タイポグラフィ / モーション / 編集

## 難易度
★3

## 使用頻度
A — サビ持ちのリリックビデオなら主砲になれる。1曲内では1〜2セクション限定が効く

## 使用タイミング
- サビ / ドロップ / ラストサビ（Aメロ・Bメロでは使わない＝落差が本体）

## 演出内容
具体値（参考MVの2fps/12fpsフレーム解析による実測）:
- **着地間隔**: 1拍=1ワード（BPM150なら0.4s間隔）。文節単位（「今すぐ」「もう一回」）で区切る
- **着地の質感**: 出現2〜4フレームはモーションブラー（進行方向スメア）→急停止でシャープに確定。fade-inは使わない（「置く」のではなく「叩きつける」）
- **加算**: 前のワードは残す。1フレーズで3〜6ワードの群れを作る → フレーズ切替で全消去（ワイプ/ホワイトアウト/ハードカット）
- **サイズミキシング**: 同一フレーズ内で最小:最大＝1:4〜1:8。キーの1文字だけ画面高の60〜100%（はみ出し可）。例: フレーズ中のキーの漢字1文字が画面中央を占有
- **配置**: ベースライン回転±5〜20°、階段状に下降/上昇、中央を避けて対角に流す。群れの重心は画面中心付近を維持
- **エスカレーション**: サビ1=平面ベタ塗り（1色）→ ラスサビ=同じ動きのまま発光素材（白＋プリズム縁/グロー）に差し替え。「動きは同じ・素材だけ昇格」が効く
- 実装（Remotion）: 1ワード=1 `<Sequence>`、`from`を拍グリッドに吸着。ブラーは`filter: blur()`+`translate`の2〜4フレーム減衰で安価に作れる

## カメラワーク
- なし（固定）〜極緩ズーム。文字が動くのでカメラは止めるほど効く

## 編集
- フレーズ切替の一掃に Smash Cut / ホワイトアウト / light-flood-wipe を使う

## 色
- **メインカラー:** 背景と補色関係の高彩度1色（例: 空色背景×黄色文字）
- **アクセントカラー:** ラスサビで白発光＋プリズム虹縁
- **相性の良い配色:** 背景が極彩色なら文字は白or黒の無彩色に逃がすと可読性が残る

## ライティング
- ラスサビ昇格時のみ: 文字自体を光源化（screen合成＋ブルーム）

## リリックとの相性
★5 — 歌詞そのものを主役にする演出。歌詞が弱い曲では使わない

## AI画像生成で再現する場合
- 本演出はコンポジット側（Remotion/AE）で実装する。AI生成は背景プレートのみ
- **共通キーワード:** 背景は文字の可読域（空・余白）を上下どちらかに確保した構図で生成する

## AI動画生成で再現する場合
- **重要要素:** 文字レイヤーはAI動画に含めない（崩れる）。背景ループのみAI、文字は必ずオーバーレイ
- **動画生成（providers.video）:** 背景ループ素材のみ担当させ、文字は後段で重ねる

## 注意点
- 群れが育つほど新ワードの置き場が無くなる。**フレーズ設計時に最終フレームの完成図を先に決める**（行き当たりで置くと後半が潰れる）
- 全ワード可読を狙わない。読ませるのはキーワードだけ、残りは「音圧の視覚化」と割り切る
- 毎サビ使うと飽きる。サビ1とラスサビで素材昇格の落差を作る
- 着地ブラーは2〜4フレーム厳守（長いと「滑って」打点がぼやける）

## 品質チェック
- 着地がビートと1フレーム以内で合っている
- 新ワードが既存ワードのキー文字を隠していない
- フレーズ切替で全消去が入っている（群れの持ち越しが無い）
- 1フレーズ内のサイズ比が1:4以上ある
- ラスサビで素材（色/発光）が昇格している

## バリエーション
1. **単色ベタ版** — サビ1標準。背景補色の1色
2. **発光プリズム版** — ラスサビ昇格用。白＋虹縁グロー
3. **1文字爆弾** — フレーズ最後の1文字だけ画面はみ出し級（「あぁ!」）
4. **二連呼** — 同ワードをサイズ違いで2回置く（「絶対に絶対に」）
5. **カウントダウン型** — 4拍で4ワード→ドロップ頭で一掃＝ビルドアップ転用
6. **通過スタンプ型** — 着地させず、超巨大半透明ワードが多フレームかけて画面を横断する。「積む」の対＝「通過する」。タイポ自体がカメラワークの代替になる
