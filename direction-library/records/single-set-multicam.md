# 単一セット×多カメラ / Single Set, Many Cameras

## 概要
セット（背景・被写体）を1つしか持たないまま、**カメラの種類だけで画変わりを作り**長尺を持たせる方針。素材追加ゼロで「ショット数」を増やす、MV最大のコスパ技法。

## 主な用途
- 素材が1枚絵/1セットしか無いのに3〜4分の尺を持たせる
- AI生成素材の枚数を増やせない（コスト/同一性維持）状況での画変わり確保
- 長尺の中盤〜後半が単調になりやすい問題の解消

## 感情
- 没入 / 荘厳 / 高揚 / 神秘 / 孤独 / 決意 / 陶酔（＝セット側の感情に従属する。本技法自体は中立）

## 演出カテゴリ
- カメラ / 構図 / 編集

## 難易度
★3

## 使用頻度

## 使用タイミング

## 演出内容
実証値（240秒の長尺を門＋花畑の1セットで通した実例）:
- **カメラを10〜14種用意し、セクションに割り当てる**。実例の内訳:
  - 空間系: `establish`(全景) / `dive`(突入) / `tunnel`(回転しつつ接近) / `spiral` / `dollyLow`(低空前進) / `overheadDescend`(真上から降下) / `sideTrack`(横移動) / `craneUp`
  - 被写体系: `charFull` / `charTrackIn` / `charBustR` / `charBustL` / `charFace` / `charFeet`
  - 打点系: `snap`(瞬間切替) / `punchIn`
- **Dropごとに別セットのカメラを割り当てる**（同じDropで同じカメラを使い回さない）。Verseは構図バリエで細分割
- **同一構図を8小節以上続けない**（続けると「壁紙」化する）
- **2D素材でも成立させる**: 3Dが無くても「スケール＋位置＋トリミング」で A=標準 / B=顔寄り(1.5〜1.8倍・目元を三分割交点) / C=引き の3構図を作り巡回する。2Dは正面固定にして歪ませない（`charFace` 系は camX/camY 平行移動＋ズームで配置）
- **光条件を変えて同一カットを再利用**: hue-rotate / 逆光オーバーレイ / 彩度で別表情に。素材5本で表情10以上
- **枠正規化して設定を流用**（実装知）: キャラ画像を「頭頂y0.16 / 足元y0.96 / 水平中央 / 足元固定」で正規化しておくと、差分イラストを差し替えても既存のカメラ設定がそのまま効く

## カメラワーク
- 本レコードが対象そのもの（Push In / Pull Out / Orbit / Crane / Dolly / Top Shot / Track を組み合わせて使う）

## 編集
- カット頭は入場アニメより**前カットとの落差**を作る（smash-cut原理）。whip-pan で構図ジャンプを隠して繋ぐのも有効

## 色
- **メインカラー:** セットに従属
- **アクセントカラー:** 同一セット再利用時の差別化に色を使う（光条件の変更）
- **相性の良い配色:** セクションごとに色温度を変える color-shift と併用すると画変わりが二重になる

## ライティング
- 光源を1つに絞ると、カメラを変えても世界が破綻しない（実例では赤い門だけを光源にした）

## リリックとの相性
★4 — カメラが動くぶん歌詞は定位置固定でよい（動を分担する）

## AI画像生成で再現する場合
- **共通キーワード:** セットは1つだけ生成し、アングル違いを追加生成しない（同一性が崩れるため）。カメラワークはコンポジット側で作る
- 3D（R3F/Blender）ならカメラは無限に増やせる＝本技法の相性は3Dが最良

## AI動画生成で再現する場合
- **重要要素:** AI動画に複数アングルを作らせない（別世界になる）。1クリップを撮り分けるのはコンポジット側
- **動画生成（providers.video）:** ループ素材1本を作り、Remotion側でスケール/位置/光条件を変えて多ショット化する

## 注意点
- カメラの種類を増やすだけでは足りない。**セクションのエネルギーとカメラの激しさを対応させる**（静=ドリフト、drop=打点）
- 同一構図の連続が最大の敵。**5秒間隔のコンタクトシートで隣接タイルが同じに見えたらNG**（ffmpeg で 0.2fps 抽出してタイル化すれば作れる）
- 被写体が2D素材の場合、斜めカメラで歪むと一発でバレる＝正面固定＋平行移動で逃がす
- 長尺ほど後半に「被写体が居ないカット」が増えがち。キャラの再登場リズムを設計する

## 品質チェック
- 同一構図が8小節以上続いていない
- セクションのエネルギーとカメラの激しさが対応している
- 5秒間隔コンタクトシートで隣接タイルが別の画に見える
- 2D素材が斜めカメラで歪んでいない
- 被写体不在のカットが連続しすぎていない

## バリエーション
1. **3Dセット型** — R3Fで実カメラを14種
2. **2.5D擬似型** — 1枚絵をスケール/位置/トリミングでA/B/C構図巡回
3. **光条件バリエ型** — 同一カットをhue-rotate/逆光/彩度で別表情に再利用
4. **枠正規化型** — 被写体を規格化して差分素材を無コストで差し替え
5. **レイヤー分離型** — 背景と被写体でカメラ追従係数を変える（bg×1.4 / char×1.0＝即席パララックス）
