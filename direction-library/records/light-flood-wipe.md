# 光フラッドワイプ / Light Flood Wipe

## 概要
画面の一方向から光が**0.5〜1.5秒かけて流入**し、ほぼ全白（97〜100%）に達してから引いていき、**引き際に次のシーンを開示**する転換。ハードカットを「光に包んで」渡すことで、シーン切替を編集ではなく**世界の側の出来事**（夜明け・解放・浄化）に見せる。

## 主な用途
- セクション転換（2番→間奏、落ちサビ→ラスサビ）を感情の転換点として演出する
- beat-word-stack 等で育てた歌詞の群れの一掃
- 「暗い世界→明るい世界」の世界観スイッチ（色温度ごと切り替える）

## 感情
- 解放 / 多幸感 / 希望 / 覚醒 / 神聖 / 浄化

## 演出カテゴリ
- 編集（転換）/ ライティング

## 難易度
★2

## 使用頻度
A — 1曲2〜3回まで。多用すると転換の重みが消える

## 使用タイミング
- サビ前 / 間奏頭 / 落ちサビ明け / ラストサビ頭 / アウトロ（余韻の消し方として）

## 演出内容
具体値（参考MVの12fpsフレーム解析）:
- **流入**: 光源方向（画面左/右/奥）から暖色光が流入。0.5〜1.5秒（曲のタメに合わせる）。screen/add合成で背景の彩度を漂白しながら侵食
- **ピーク**: 全白97〜100%を2〜6フレーム維持。**白ピーク中に次シーンの歌詞/被写体を先行フェードインさせてよい**（白が「読み込み画面」になり、開示が2段になる）
- **引き**: 流入より速く引く（0.3〜0.8秒）。引き際に次シーンが「光の中から現れる」
- **色**: 転換先の世界観の色を光に先取りさせる（夜明けへの転換なら暖色アンバー、電脳なら白青、虹世界ならプリズム多色）
- 実装（Remotion）: 放射/線形グラデの白レイヤーを`mixBlendMode: screen`で重ね、opacity+scaleを非対称イージング（流入ease-in / 引きease-out）で駆動。ピークで下のレイヤーツリーを丸ごと差し替える

## カメラワーク
- なし（固定）〜流入方向への微パン（光に「引っ張られる」感）

## 編集
- 本体が転換。ピークのフレームで実カットを隠す（match-cut不要になる）

## 色
- **メインカラー:** 転換先世界の色を持つ光（アンバー/白青/プリズム）
- **アクセントカラー:** ピーク直前のフリンジ（縁の色収差）
- **相性の良い配色:** 転換前後で色温度を対比させる（寒色世界→暖色光→暖色世界）

## ライティング
- 逆光扱い。被写体は流入中シルエット化してよい

## リリックとの相性
★4 — 白ピーク中の歌詞先行表示が強い。ただし読ませたい歌詞は白100%を避けピーク後に確定させる

## AI画像生成で再現する場合
- **共通キーワード:** blinding light flooding from left, overexposed, bloom, backlit silhouette
- 転換前後の2プレートを生成し、光レイヤーはコンポジット側で作る方が制御しやすい

## AI動画生成で再現する場合
- **重要要素:** AI動画に白飛びまで焼き込ませない（戻せなくなる）。光はRemotion側でオーバーレイ
- **動画生成（providers.video）:** 「light gradually flooding in from the right, increasing exposure」等は動くが、ピーク白の維持フレーム数を制御できないため非推奨

## 類似演出
- flash-cut（1〜3フレームの瞬間白。本レコードは尺と方向性を持つ）
- bloom-overexposure（常時質感。本レコードは転換機能）
- lens-flare（光源の飾り。フラッドの起点に併用可）
- whip-pan（ブラーで隠す転換の運動版）
- smash-cut（落差転換の無光版）

## 相性の良い演出
- beat-word-stack（群れの一掃）/ god-rays / lens-flare / bloom-overexposure / color-shift（転換先の色設計）/ silhouette / crane-shot / particle-rise / slow-motion（ピーク前のタメ）/ seamless-loop（転換先背景）

## 相性の悪い演出
- strobe-light（白の価値が下がる・光過敏リスク加算）
- datamosh（光の清潔感と喧嘩）
- glitch-cut（転換手段が二重になる）
- vignette強がけ（流入の方向性を殺す）
- negative-invert（白ピークと反転白が混同される）

## 注意点
- 白100%の維持は6フレーム以内。長いと「機材トラブル」に見える
- 流入と引きを同速にしない（対称だと機械的。流入ゆっくり→引き速くが自然）
- 連発禁止。転換の格（サビ前＞間奏＞その他）に合わせて1曲2〜3回まで
- 白ピークはYouTube圧縮でバンディングが出やすい＝微グレインを乗せる

## 品質チェック
- 光の流入に方向がある（全面同時フェードになっていない）
- 白ピークが2〜6フレームに収まっている
- 引き際に次シーンが開示される（白が明けてからカットしていない）
- 光の色が転換先の世界観の色を先取りしている
- 微グレインでバンディング対策済み

## バリエーション
1. **暖色夜明け版** — アンバー/ピンクゴールド。喪失→解放の定番
2. **プリズム版** — 多色フリンジ付き白。虹世界への転換
3. **カラードレイン反転版** — 彩度を抜き切ってから白→彩度全開で開示
4. **半ワイプ** — 白60%で止めて引く＝場面は変えず感情だけ上げる
5. **逆フラッド** — 引きから始めて流入で終わる＝希望→閉塞の下降転換
