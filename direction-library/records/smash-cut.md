# スマッシュカット / Smash Cut

## 概要
静的なカットから対極の動的なカットへ、トランジション一切なしで切り替えるハードカット。音楽の落差（無音ブレイク→Drop）を映像の落差で倍加する、MV編集の最強の起爆装置。技術は「切るだけ」、本体は前後の落差設計。

## 主な用途
- サビ頭 / Drop頭の起爆（最頻出）
- 曲開始1音目のインパクト（黒画面→いきなり本編）
- ビルドアップ終端の無音ブレイク→Dropの同期
- 落サビ（動→静の逆スマッシュ）
- コメディ的なオチ・ツッコミの「ぶった切り」

## 感情
- 衝撃
- 高揚
- 解放
- 爽快
- 緊張
- 覚醒

## 演出カテゴリ
- 編集

## 難易度
★1（切るだけ。ただし落差が出るのは前後カットを設計した場合のみで、素材任せだと不発する）

## 使用頻度
S — サビ/Dropを持つ曲ならほぼ必ず1回は使う。EDM/ボカロでは構造の一部。

## 使用タイミング
- 曲開始（無→1音目と同時に画が立ち上がる）
- ビルドアップ終端（1拍の無音→Drop頭で世界が切り替わる）
- サビ頭・Drop頭の1拍目
- ラストサビ頭（曲中最大の落差をここに温存する設計も強い）
- 落サビ頭（動→静の逆向き）

## 演出内容
- **基本:** 「静の画」→「動の画」を予告なしのハードカットで接続。フェード・ワイプ等の緩衝は入れない。
- **カット点の精度が生命線。** Drop/サビ頭の1拍目に±1フレーム（24fpsで±41ms）。体感同期を狙うなら映像を1〜2フレーム先行させる（視覚の知覚が聴覚よりわずかに遅いため）。DAW/編集ソフトの波形でキック頭を目視特定してから切る。
- **落差は4軸で反転させる:** ①モーション量（静止→激しい動き）②明度（暗→明 or 明→暗）③彩度（低→高）④ショットサイズ（寄り→引き、または逆）。最低2軸、理想は3軸以上を同時反転。
- **前カットの直前2〜4拍は動きを殺す。** 無音ブレイクと同期して「時間が止まった」状態を作るほど、カット後の爆発が効く。
- **実写:** 撮影段階から「静の画」「動の画」をペアで設計。静=三脚固定・被写体静止、動=手持ち・群舞・広角。
- **アニメ/イラスト:** 止め絵（口パクのみ）→高密度作画カットへ。作画枚数の差そのものが落差になる。リリックビデオなら「文字なし静止背景→特大タイポ＋背景一新」。
- **3DCG:** 同一シーンでもライティング・カメラ・ポストエフェクトの一括切替でスマッシュが作れる（アセット流用が効く）。

## カメラワーク
- なし（編集演出）。ただし素材側のカメラを対比させる: 前=完全固定、後=手持ち大揺れ/高速オービット
- 前カット終端をPush Inの寄り切りにするのが最頻出コンボ

## 編集
- 本演出そのもの
- 動側の頭に白1フレームを重ねる（flash-cut併用）とさらに強い
- サビ頭から2〜4カットを1拍ごとに連打する「カットイン連打」へ発展可

## 色
- **メインカラー:** 制約なし（落差構造が本体）
- **アクセントカラー:** 前後で明度・彩度を反転させる。暗い青（静）→高彩度の赤/ネオン（動）が定番
- **相性の良い配色:** 静側は2色以内の抑制、動側で色数を一気に解放すると「世界が開く」

## ライティング
- 静側: Silhouette / 単一光源のロー・キー
- 動側: Neon / Strobe / ハイ・キーで光量を一段爆発させる
- 「カットと同時に照明が点く」設計は照明のみでもスマッシュ相当の効果

## リリックとの相性
★★★★☆ — 文字量の落差で同じ構造が作れる（静側は文字ゼロ→動側頭で特大の1語をドン）。サビ頭のタイトル出しと同期させると強力。ただし静側に長文を残すとカットの衝撃が濁る。

## AI画像生成で再現する場合
静止画では「静の画」「動の画」を1組として設計する。
- **共通キーワード:** 静側= still, minimal, dark, empty space, single light source ／ 動側= dynamic, explosive, high saturation, crowded frame, motion blur
- **画像生成（providers.image）:** 同一キャラは参照画像で保ち、環境と照明の語だけ入れ替える（dark empty room → neon stage, crowd, confetti）。「the same girl, but now the stage explodes with light and movement」のように差分を文章で書く

## AI動画生成で再現する場合
**生成ではなく編集で作る演出。** AIは素材供給に徹し、カットは編集ソフトで打つ。
- **素材生成の注意:**
  - 動側素材は冒頭がゆっくり立ち上がる癖（生成AI共通）があるため、**中盤の一番激しい瞬間から使えるよう長めに生成して頭をトリム**する
  - 静側素材は終端フレームが安定していること（静止耐性）。微動のみのループ系素材が最適
  - 色・構図の反転は生成時から指定（編集で無理にグレーディングすると破綻する）
  - 同一人物に見せたいなら同一参照画像からimage-to-videoで2本生成
- **ffmpeg:** 2素材を無加工でハード連結する例（静4.0秒＋動素材の1.2秒目以降）:
  ```
  ffmpeg -i quiet.mp4 -i drop.mp4 -filter_complex "[0:v]trim=0:4.0,setpts=PTS-STARTPTS[a];[1:v]trim=start=1.2,setpts=PTS-STARTPTS[b];[a][b]concat=n=2:v=1[v]" -map "[v]" out.mp4
  ```
- **Premiere:** オーディオ波形でキック頭にマーカー（M）→ 編集点をマーカーにスナップ。速度は一切いじらない
- **After Effects:** レイヤーのイン点をビートマーカーに合わせるだけ。動側頭に白平面1フレームを重ねる場合もここで

## 類似演出
- flash-cut（白/黒コマで衝撃を作る近縁）
- match-cut（同じハードカットだが「繋げる」思想で真逆）
- glitch-cut（ノイズを緩衝材にした急転換）
- zoom-punch（カットせず瞬間加速で衝撃を作る）
- jump-cut（同一構図内の時間飛ばし）

## 相性の良い演出
- push-in（寄り切り→スマッシュでサビ頭。最強の定番コンボ）
- speed-ramp（静側をスローにして落差をさらに拡大）
- flash-cut（動側頭の白1フレームで衝撃を上乗せ）
- camera-shake（動側頭に微シェイク=着地の衝撃）
- zoom-punch（動側1カット目の頭で使う）
- color-shift（前後の色相反転を設計として組み込む）
- silhouette（静側をシルエットにして情報量を絞る）
- neon-lighting（動側の光量爆発）
- kinetic-typography（サビ頭の特大タイトル出しと同期）
- glitch-cut（2回目以降のサビ頭で変化球として使い分け）

## 相性の悪い演出
- クロスディゾルブ — 緩衝を入れた瞬間スマッシュではなくなる。定義レベルで両立不可
- light-leak — 柔らかい光のにじみが衝撃のエッジを丸める
- datamosh — 溶けの連続性がカット点を曖昧にし、落差が消える
- match-cut — 同一カット点での併用は不可（繋げるか、断ち切るか、思想を選ぶ）
- pull-out — 動側の頭で引くと勢いが減衰する。動側頭は寄りか激しい動きで

## 注意点
- **落差の9割は前カットの設計。** 静を作り込まずに切っても「ただのカット」。直前2〜4拍の静止を惜しまない
- カット点1フレームのズレで台無し。耳ではなく**波形を見て**合わせる
- 1曲2〜3回まで。連発すると脳が慣れて全部効かなくなる（最大の1発をラスサビに温存する配分を先に決める）
- 動側素材の立ち上がりが緩いと不発。頭から全開の素材を用意する（AI生成なら中盤トリム）
- 音側に無音ブレイクや音圧差がないのに映像だけスマッシュすると浮く。**音の落差とセットで**設計する

## バリエーション
- **無音ブレイク型:** 1拍の完全無音＋静止→Drop頭で同時爆発。EDMの様式美
- **フラッシュ挟み型:** カット点に白1フレームを挟む。衝撃+20%、flash-cutとのハイブリッド
- **逆スマッシュ:** 動→静。落サビ頭・アウトロで「世界から音が消える」感覚
- **カットイン連打型:** サビ頭から1拍ごとに2〜4連続スマッシュ。情報の洪水で圧倒する
- **開幕スマッシュ:** 黒画面2秒→曲頭1音目で本編へ。冒頭離脱を防ぐ縦ショート/切り抜き向き
- **ジャンプスケア型:** ホラー文脈。静寂→至近距離の顔+大音量
