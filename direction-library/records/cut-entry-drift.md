# カット入場イージング＋ドリフト / Cut Entry Easing & Drift

## 概要
1枚絵／少数素材のMVで、**カメラの動きだけで疑似的にショットを割る**運用フレーム。カット頭で ease-out（easeOutQuint）で勢いよく入り、約1秒で着地したあとは経過秒に比例してゆっくり漂い続ける。入り方の型を4つ巡回させることで「全編同一構図」の飽きを解消する。

## 主な用途
- 背景1枚＋キャラ1枚しか素材が無い状態で3〜4分の尺を持たせる
- AI生成素材を増やせない（コスト／同一性維持）状況での画変わり確保
- 歌詞リリックビデオの下地カメラ（文字は固定・世界だけ動かす）
- 曲の構造点（歌詞の切れ目／ドロップ／間奏頭）を映像側で可視化する
- 配信背景・ビジュアライザーで「止まってる感」を消す

## 演出内容

### 1. CUTS配列＝再トリガー時刻を曲の構造点に置く
カメラを「入場からやり直す」時刻を秒で配列に持つ。実例（200秒の曲・16カット）:

```
CUTS = [0, 14, 48, 61, 72, 84, 90, 98, 112, 125, 138, 152, 161, 170, 178, 190]
```

- 間隔は **最短6秒（84→90）／最長34秒（14→48）／中心値は12〜14秒**
- 置き場所は **歌詞の切れ目・ドロップ・間奏の頭**。等間隔に割ると音と無関係にブレて見える＝必ず波形／歌詞タイムを見て置く
- 「太いシンセが入る位置」などに合わせて**1〜2秒単位で追い込む**（例: 82秒→84秒）
- 場面切替をふわっと繋ぎたい箇所には再トリガーを置かない＝カットは増やすほど良いものではない

### 2. 入場＝D 1.05秒 / easeOutQuint
```
D = 1.05                       // 入場時間（30fps で 31.5 フレーム）
e = 1 - (1 - local/D)^5        // easeOutQuint: 0→1
enter = 1 - e                  // 入場オフセットの残り: 1→0
drift = local                  // 着地後の経過秒（そのまま使う）
```
- easeOutQuint は **0.21秒（6.3F）で67%、0.53秒（16F）で96.9%** 進む＝「バン、と入って、あとは吸い付くように止まる」
- ease-in-out や linear だと「カットが切り替わった」感が出ず、ただのスライドショーになる。**ease-out 一択**
- 1.05秒は 30fps 前提で「速すぎて酔わない／遅すぎてカットに見えない」の実測値。BPM 140〜160 の曲なら 0.8〜0.9秒、90 以下のバラードなら 1.3〜1.5秒に伸ばす

### 3. 着地後ドリフト＝止めない・ただし上限を切る
`enter` が 0 になった後も `drift`（経過秒）に比例して微動を足し続ける。**必ず `Math.min(drift, 30)` で上限を切る**（30秒以上のロングカットで動きが破綻するのを防ぐ）。実例の 14→48秒（34秒尺）カットがこれに救われている。

### 4. 型を4つ巡回（idx % 4）＝隣接カットが必ず別の入り方になる
| idx%4 | 型 | 入場 | 着地後ドリフト |
|---|---|---|---|
| 0 | 左からスッと | `tx = enter * -2.5%` → 0 | 右へ `+0.03%/秒`（30秒で+0.9%）、`scale 1.07 + 0.0008/秒`（30秒で1.094） |
| 1 | 奥からパンアップ | `ty = enter * +2.8%` → 0、`scale = 1.06 + enter*0.04`（1.10→1.06） | じわ上 `-0.025%/秒`（30秒で-0.75%）、`scale +0.0006/秒` |
| 2 | ズームイン | `scale = 1.16 - e*0.09`（1.16→1.07） | じわ寄り `+0.0012/秒`（30秒で1.106） |
| 3 | 奥からドリー | `scale = 1.17 - e*0.09`（1.17→1.08）＋斜め `tx = enter*2.0% / ty = enter*-1.6%` | じわ寄り `+0.001/秒` |

剰余で回すので**同じ型が隣に来ない**のが保証される。ランダム化すると同じ型が連続して「同じカットに見える」事故が起きる＝**巡回（ラウンドロビン）が正解**。

### 5. オーバースキャンとクランプ＝黒縁を物理的に出さない
- **base overscan `scale 1.06`** ＝常に6%拡大して持つ（何もしていない時も画面外に余白がある状態）
- `tx`, `ty` は最後に **±2.6% にクランプ**。1.06倍のオーバースキャンで確保できる片側余白は約3%なので、2.6%は安全マージン込みの上限
- これを入れないと「translate した瞬間に背景の端（黒）が1フレームだけ覗く」＝最も多いバグ

### 6. 歌詞はカメラの外
カメラ transform は **world（背景／装飾／キャラ／粒子／光エフェクト）を包む1枚のレイヤーにだけ**適用し、**歌詞・タイポは固定オーバーレイ**として camera の外側に置く。文字までカメラに入れると可読性が落ちる（動く文字を読ませることになる）。

### 7. 動かすべきでない場所は明示的に止める
- **Intro 0〜15秒は再トリガーせず `scale(1.04)` / `transformOrigin: '50% 70%'` で据える。** CUTS の早い要素が曲の頭で「意図なく一瞬ブレる」原因になるので、範囲 if で潰す
- 静止区間の scale と origin は**次の特殊カメラの始点と一致させる**（実例では 15秒からの消失点ドリーが `1.04 / 50% 70%` 始点＝継ぎ目ゼロ）
- 間奏の盛り上がり（125〜138秒）も **完全固定 `scale(1.06)`** にした。音が盛り上がるほどカメラを動かしたくなるが、そこは他のFX（流れるネオン／スパーク）に任せる方が強い

### 8. セクション専用カメラは巡回ロジックより先に評価して上書き
区間 if を巡回ロジックの**手前**に置く。実例:
- `15〜22s` 消失点ドリー `s = 1.04 + p^3 * 0.48`（`transformOrigin: '50% 70%'` で上ではなく道の奥へ寄せる）
- `22〜23.2s` 歌い出しでバーン登場 `scale 1.34 → 1.06`（0.4秒で着地）、`origin '58% 40%'`
- `37.4〜42.2s` タイトルコールでパンアップ＋寄り `ty 0 → -2.4% → 0`、`scale 1.06 → 1.13 → 1.06`（言い終わりで戻す）
- `125〜138s` 間奏固定

### 媒体別
- **1枚絵イラスト / 2.5D:** 本命。ただし world を1枚のレイヤーで包むと視差ゼロ＝「写真を動かした」感が残る。レイヤー分離できるなら §バリエーションの多層ドリフトへ
- **3DCG:** 実カメラの Z/XY に置き換えるだけで成立し、視差が本物になる
- **実写:** 固定カメラの長回し1本をこの手法で「割る」用途。4Kで撮って1080pで出せば ±2.6% は余裕
- **AI生成動画素材:** 素材側は動かさず（後述）、この手法を後段で当てる

- **疑似 Smash Cut:** 素材を切らずカメラの再トリガーだけで「切れた」と感じさせる本体
- **Jump Cut 代替:** 型が変わることで構図がジャンプする

## 色
- **メインカラー:** 制約なし（カメラ運用のため色非依存）
- **アクセントカラー:** 再トリガー時刻に合わせて粒子色を切り替えると「シーンが変わった」情報が増える（実例: 〜138秒 `#bfffff` / 138〜148秒 `#9aa` / 152秒〜 `#ffe6b0`）
- **相性の良い配色:** 暗いベース（例: `#05010f`）＋ネオン1〜2色。オーバースキャンで端が動いても暗部同士なので破綻が目立ちにくい

## ライティング
- Neon / Rim Light: 動きが小さいので、光の明滅の方が「時間が流れている」情報量を稼ぐ。カメラと光の周期をズラす
- Back Light: ズームイン型（型2・型3）で逆光の玉ボケが寄ってくると擬似的な奥行きが出る
- 固定区間ほどライティングを動かす（カメラを止める＝光で持たせる、の分担）

## AI画像生成で再現する場合
生成するのは**動かない1枚**。ただし ±2.6% translate ＋ scale 1.06〜1.17 で端がトリムされるので、**構図の端に情報を置かない／上下左右に10%の余白を持った広めの画**を作る。
- **共通キーワード:** wide establishing shot, generous margin around subject, subject centered, full background visible, no text, high resolution, consistent lighting
- **画像生成（providers.image）:** ショットサイズ（wide shot）をプロンプトの先頭に置き、「the whole scene is visible with empty space around the edges, camera is far from the subject」と距離を文章で書く。文字を勝手に描くことがあるので `no text, no letters` を明示し、2560px 以上に上げておくと後段の scale 1.17 でも解像度が持つ

## AI動画生成で再現する場合
**この演出は後段（編集／コンポジット）でカメラを付けるもの。AI動画側にカメラ移動を任せてはいけない。** カメラを振らせるとキャラの顔・手・服が溶け、フレーム間で別人になる。AI動画に作らせるのは「**カメラが固定された、微モーションだけの素材**」。

- **重要要素:** ①`static camera` / `fixed camera` / `no camera movement` を必ず明記 ②動くのは環境と微モーション（髪・服の揺れ、まばたき、ネオン明滅、粒子）だけ ③後段でズーム前提なので**素材は 4K（2160p）以上**か、生成上限が 1080p なら scale 1.17 に耐えるよう構図を広めに ④ループ素材にしておくとカット尺（6〜34秒）に自由に伸ばせる
- **動画生成（providers.video）:** カメラ指定は固定／未指定にし、`static shot, locked-off camera, no zoom, no pan, only her hair and the neon lights move` を文頭に。5秒素材をループ化して後段で必要秒数だけ繋ぐ。
  放っておくと微妙にドリフトすることがあるので、出力後に**素材側の意図しない動きが無いか1本見る**
- **後段（Remotion / AE / Premiere）:** 生成した固定素材を1枚のレイヤーに包み、本レコードの CUTS ＋ easeOutQuint ＋ drift を transform で当てる。Remotion なら `cameraTransform(t)` を返す純関数1つ（100行未満）で済む

**後段カメラ実装（TypeScript / Remotion）:**
```ts
const CUTS = [0, 14, 48, 61, 72, 84, 90, 98, 112, 125, 138, 152, 161, 170, 178, 190];
const easeOutQuint = (p: number) => 1 - Math.pow(1 - Math.min(1, Math.max(0, p)), 5);
// カット頭 cs / インデックス idx を求め、local = t - cs
const e = easeOutQuint(local / 1.05), enter = 1 - e, drift = Math.min(local, 30);
// idx % 4 で 0:左からスッと / 1:奥からパンアップ / 2:ズームイン / 3:奥からドリー
// 最後に tx,ty を ±2.6% にクランプ、base scale 1.06
```

## 注意点
- **等間隔に CUTS を置くと即バレる。** 音を聞かずに「10秒ごと」で割ると、映像が曲と無関係に動く機械になる
- **ランダムで型を選ぶな。** 同じ型が2回連続すると「切れていない」と見える。`idx % 4` の巡回で機械的に保証する
- **入場を ease-in-out にしない。** 「バン」が消えてスライドショーになる
- **`Math.min(drift, 30)` を忘れると**ロングカット（30秒超）でドリフトが走りすぎ、クランプに張り付いて動きが止まったように見える／scale が肥大する
- **クランプ（±2.6%）を入れる前にオーバースキャン（1.06）を決める。** 順序を逆にすると余白計算が合わず黒縁が出る
- **transformOrigin を意識する。** `50% 50%` 固定で寄ると空や天井へ寄ってしまう。地面／道の奥へ寄せたいなら `50% 70%`、キャラの顔へ寄せたいなら `58% 40%` のように**寄りたい先を origin にする**
- **セクション専用カメラは必ず巡回ロジックより先に書く。** 後ろに書くと到達せず無効になる
- **曲の頭は止める。** CUTS の最初の要素があると Intro で意図しない微ブレが出る。範囲 if で明示的に据える
- **world を1枚で包むと視差ゼロ。** 「絵を動かした」感が残るのは仕様。気になるならレイヤー分離して速度差を付ける
- 素材解像度が 1080p だと型3の `scale 1.17` で17%拡大＝甘くなる。**素材は 2560px 以上**を用意する

## 品質チェック
- [ ] **translate/scale が最大まで振れたフレームで、画面四辺に背景外の黒（黒縁）が1pxも出ていないか**（各型の入場0フレーム目と、drift 30秒到達フレームを静止画で確認）
- [ ] **歌詞が表示されている全区間で、カメラの移動量が「読める」範囲に収まっているか**（歌詞1行の表示中に scale 変化 0.02 以内・translate 1% 以内）
- [ ] **CUTS の各時刻が、波形上の構造点（歌詞頭／キック／シンセ入り）と2フレーム以内で合っているか**
- [ ] **Intro（0〜15秒）と意図的固定区間（実例125〜138秒）で、カメラが1pxも動いていないか**
- [ ] **隣接する2カットの入り方が別の型になっているか**（連続する再トリガーを並べて目視。同じ動きが2回続いていないこと）

## バリエーション
- **多層ドリフト（マルチプレーン）:** world を前景／主体／背景の3レイヤーに分け、同じ CUTS で係数を 1.4 : 1.0 : 0.6 に振る。視差が出て「写真を動かした」感が消える
- **6型巡回（`idx % 6`）:** 既存4型に「右からスッと（`tx = enter * +2.5%`）」「上から降りる（`ty = enter * -2.8%`）」を追加。5分以上の長尺や、カット数20本超のときに使う
- **BPM同期版:** D を秒ではなく拍で持つ（`D = 60/BPM * 2` ＝2拍で入場）。CUTS も小節番号で持ち、テンポチェンジのある曲でも構造と一致し続ける
- **ドロップ強化版:** ドロップの CUTS だけ型を強制的に 3（奥からドリー）にし、D を 0.6秒・入場 scale を 1.28 に上げる。他は通常巡回。**盛り上がりの1点だけ入場を強くする**
- **静止優勢版（バラード／アンビエント）:** D を 1.5秒、入場オフセットを半分（tx ±1.2% / scale 1.10→1.06）、CUTS 間隔を 20〜30秒に。ドリフトは残す＝ほぼ静止だが死んでいない
- **反転ドリフト版:** 着地後のドリフトを**入場と逆方向**に流す（左から入って、着地後さらに左へ）。押し戻される感じが出て不安・喪失に寄る
- **回転を足した版:** ドリフトに `rotate(drift * 0.03deg)` を加える。ただし回転はクランプ計算を壊すので overscan を 1.10 に上げ、translate クランプを ±1.8% に絞る
