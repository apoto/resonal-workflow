# 段階消灯 / Progressive Blackout

## 概要
画面をセル（矩形タイル）に分割し、**街の灯・窓明かり・ネオンをセル1個ずつ不可逆に消していく**ビルドアップの視覚化。序盤は疎に、終盤は一斉に落ちる**加速カスケード**で「溜め」を作り、全暗に到達した数秒後にドロップで一気に光が戻る。光が増えて転換するのではなく、**光が減って無くなる片道の消失**が本体。

## 主な用途
- ドロップ直前11秒のビルドアップを「光の残量」でカウントダウンさせる（音のライザーと同じ形を画で描く）
- 停電・電源喪失・圏外・サーバー落ち・都市の死といった世界側の異変
- 全暗＝キャラのシルエットだけを残し、ドロップで色を全復帰させる落差づくり
- 歌詞の意味（「消えていく」「圏外へ」「もう見えない」）を背景側で直訳する
- アウトロで曲を終わらせる（余韻を残さず街ごと落として終わる）

## 難易度
★3 — 実装自体は矩形の opacity 切替だけで簡単。**難所は「消灯時刻の分布設計」で、ここを外すと分割数をいくら上げても効かない**（→注意点）。

## 使用頻度
B — 1曲1回。曲中で最大のビルドアップ1箇所に限定する。2回やると2回目の全暗が「またか」になり、ドロップの価値が下がる。

## 使用タイミング
- ビルドアップ全長（実装例では 48.0〜59.0秒の11秒間）
- 全暗の維持（59.0〜61.3秒＝約2.3秒。ここにカットインを差す）
- ドロップ（61.3秒で光・彩度・輝度を1フレームで全復帰）
- 落ちサビ／アウトロ（消し切って終わる用途）

## 演出内容
実装例（Remotion / 30fps / BPM150.10）の確定値。

**1. グリッド**
- 背景画像の**上に** CSS Grid を重ねる。`COLS = 36` × `ROWS = 20` = **720セル**（16:9で1セル ≒ 53×54px @1920×1080＝ほぼ正方）
- セル色は **`#03000a`**。純黒 `#000000` にしない＝わずかに紫を残すことで「灯が落ちた夜の街」であって「信号断」ではないことを保つ（ベース背景は `#05010f`）
- グリッドは区間内のみマウント（`t >= 47.8 && t < 61.3`）。720 div を常時描画しない＝レンダー負荷を区間に閉じる

**2. 消灯時刻の分布（この演出の心臓）**
```ts
const hash01 = (k: number) => {
  const x = Math.sin(k * 127.1 + 311.7) * 43758.5453;
  return x - Math.floor(x);           // 決定論的疑似乱数 0..1
};
const off = 48 + 11 * Math.pow(hash01(k), 1 / 3);  // セルkの消灯時刻
const cellOp = t >= off ? 1 : 0;                    // 一度消えたら戻らない
```
- `hash01(k)` は **k から一意に決まる**＝毎フレーム同じ値。`Math.random()` を使うとフレーム毎に再抽選されてセルがちらつき、演出が崩壊する
- **`^(1/3)`（cube-root）がキモ。** ハッシュの低域が引き伸ばされ高域が圧縮される＝**バックロード分布（後ろ寄せ）**。序盤は疎、終盤に大量に落ちる
- 実測の消灯率（720セルを実計算）: **48.7s 1個目 → 51s 3.2% → 53s 11.5% → 55s 27.4% → 56s 40.6% → 57s 55.1% → 58s 75.6% → 58.5s 86.7% → 59.0s 100%（全暗）**
- 対して**線形（`^1`）だと 55s で 64.4% / 57s で 81.7%** ＝半分過ぎた時点でもう真っ暗＝溜めが出ない。指数を上げるほど後ろ寄せが強まる（1/2＝穏やか、1/3＝実用、1/4＝終盤が急すぎて「ブツッと消える」に近づく）

**3. 全暗の維持とカットイン**
- 59.0で全暗、ドロップは61.3＝**2.3秒の空白**。この間、無処理だと確実に間延びする
- **60.0 / 60.45 / 60.9 秒**でグリッド全体の `opacity` を **0.09秒（30fpsで約2〜3フレーム）だけ 0** にする＝下のネオンが一瞬だけ覗く
```ts
const cutIn = (() => {
  for (const c of [60.0, 60.45, 60.9]) if (t >= c && t < c + 0.09) return 0;
  return 1;
})();
```
- 間隔0.45秒は拍（0.4秒 @BPM150）から**意図的に少しずらしている**＝拍ジャストだとストロボに聞こえ、消失の不気味さが「クラブの照明」に落ちる

**4. キャラの同期処理（全暗の中にシルエットを残す）**
- キャラ側: `interpolate(t, [54, 56, 60.5, 61.3], ...)` で
  - `saturate`: 1 → **0**（54→56秒の2秒で完全脱色）
  - `brightness`: 1 → **0.32**（同区間。真っ暗にせず輪郭が読める最低値）
  - 60.5→61.3 で両方 1.0 へ復帰＝ドロップで色と光が戻る
- 消灯が半分を超える55〜56秒に脱色をぶつける＝「街が落ちる」と「本人も色を失う」が同時に見える

**5. 媒体別**
- **実写:** 全カットを一発で撮り、消灯はコンポジット（マスク付き矩形の連番 opacity）で作る。実際に街の窓を1個ずつ消すのは不可能なので、**素材は「全点灯の街」1プレート**で足りる
- **アニメ／イラスト:** 1枚絵の上にグリッドを重ねるだけで成立＝作画コストゼロ。窓・看板の位置とセル境界が一致していなくても、密度が高ければ気にならない（720分割の効能）
- **3DCG:** 窓ごとの emissive マテリアルを個別に落とせるので、セル矩形でなく**実際の窓形状**で消せる（最上位品質）。ただしマテリアル数が増えるのでインスタンス化前提

## カメラワーク
- なし（固定〜微スクロール推奨）。実装例では背景を横 90px → -90px でゆっくり流しつつ消灯を進行させる
- 併用するなら **push-in をビルドアップ全長で微量（scale 1.00→1.04）**。消灯の加速と寄りの加速を同じカーブに乗せる
- 全暗中はカメラを止める（動いても見えない＝無駄）

## 編集
- 全暗中の **カットイン**（0.09秒 × 3回）＝実質 flash-cut の反転版（白1コマではなく「元画1コマ」を差す）
- ドロップは **smash-cut**：全暗から1フレームで全開。フェードで戻すと落差が死ぬ
- 全暗の闇にカットを隠せる（jump-cut / 背景プレート差し替えが自由＝繋ぎコストゼロ）

## 色
- **メインカラー:** 消灯セル `#03000a`（僅かに紫を残した黒）／ベース背景 `#05010f`
- **アクセントカラー:** 消灯前のネオン残光 — シアン `rgba(120,220,255)` ／マゼンタ `rgba(255,80,220)`。カットインで覗くのはこの2色
- **相性の良い配色:** 暗い夜景ベース（平均輝度15〜25%）＋高彩度ネオン。**明るい高キー画面には効かない**（消しても差が出ない）

## リリックとの相性
★4 — 背景が単調に暗くなっていくので**文字の可読性が上がっていく**。ビルドアップの歌詞（「消えていく」「圏外」「見えない」）を消灯の進行に合わせて置ける。ただし**全暗区間に長い歌詞を置くのは非推奨**＝画に文字しか無くなり、ドロップの爆発が「文字が消える」だけの変化になる。全暗中は1〜2語、またはブランクにする。

## AI画像生成で再現する場合
生成するのは**「全点灯の状態」1枚だけ**。消灯はコンポジットで作る＝AIに段階を作らせない。
- **共通キーワード:** night cityscape, dense lit windows, thousands of tiny light points, neon signs, high window density, view from above, no people
- **画像生成（providers.image）:** **窓の密度を上げるのが唯一の要件**（消せる灯が多いほど段階が細かく見える）。「every single window is lit」と「全部点いている」を文章で明示し、空はほぼ黒に僅かな紫と書く。暗部が潰れた素材は消しても差が出ない
- **補助プレート:** 同構図の**全消灯版**（窓が全部暗い夜景）を1枚追加生成し、グリッド消灯の下敷きにすると `#03000a` のベタより自然（セルが「暗い窓」に変わる）

## AI動画生成で再現する場合
- **重要要素:** **AI動画に消灯を作らせない。** 段階消灯は「何個目が何秒に消えるか」の**時刻制御が本質**であり、AI動画はそれを1つも保証できない（勝手に点き直す・全体が均されてフェードになる・窓が別物にモーフする）。**素材＝点灯した街の微動ループ／消灯＝コンポジット** の分業が唯一の安定解。
- **動画生成（providers.video）:** `neon city at night, all windows lit, subtle light flicker, slow camera drift` で**5秒ループ素材**だけ作り、Remotion/AE 側で720分割グリッドを重ねる。`lights turning off one by one` `blackout` は再現されず画面全体のフェードになる＝使えるのは「停電後の暗い街」を別プレートとして作る用途のみ。
- **手数の目安:** 点灯ループ5秒1本＋コンポジット30分。AI動画で段階を粘るより10倍速い

## 注意点
- **分割数だけ上げても効かない。** 「細かく・最初はゆっくり・最後は一斉に」は **①分割数を数百セル級に ②分布を等速→バックロード（cube-root）** の**2段で初めて成立**する。分割数を上げただけで分布が等速だと「細かいが単調」になる（＝均等に減るだけ）。
- **`Math.random()` を使わない。** Remotion は同一フレームを再評価するので、乱数は毎回違う値を返しセルがちらつく。**必ず `k` から決まる決定論的ハッシュ**にする。
- **一度消えたセルを戻さない。** `t >= off ? 1 : 0` のように単調にする。戻すと strobe-light に化けて不可逆性が消える。
- **消灯セルを純黒 `#000000` にしない。** 黒ベタは信号断・レンダー事故に見える。`#03000a` のように色を1〜3%残す。
- **全暗を2秒以上続けるならカットイン必須。** 無処理の全暗は視聴者に「動画が終わった／エンコード事故」と判定されて離脱される。0.09秒 × 3回で足りる。
- **カットインを拍ジャストに置かない。** BPM150（拍0.4秒）に対し0.45秒間隔＝わずかに外す。ジャストだとクラブのストロボに聞こえて不気味さが消える。
- **全暗は動画サイトの再圧縮の鬼門。** 低ビットレートで暗部にブロックノイズ・バンディングが出る。微グレイン（不透明度2〜4%）を全暗区間に乗せる。
- **明るい素材では成立しない。** 昼景・高キー画面では「消える」変化が読めない。夜景・暗所・ネオン前提。
- **キャラを真っ黒に落とさない。** brightness 0 にすると「いなくなった」に見える。0.30〜0.35 で輪郭を残すのが「全暗の中に居る」。

## 品質チェック
- 区間の前半（経過50%時点）で消灯率が30%以下に収まっている＝後ろ寄せになっているか（等速なら約50%になる＝NG）
- 全暗到達がドロップより前で、かつ全暗の維持が1.5〜2.5秒に収まっている
- どのセルも一度消えたあと再点灯していない（1フレームずつ送って確認）
- 全暗区間にカットインが2回以上あり、各回0.15秒以内で終わっている
- ドロップの1フレームで彩度・輝度が全復帰している（フェードで戻っていない）

## バリエーション
1. **加速カスケード（標準・cube-root版）** — `off = T0 + L * hash^(1/3)`。序盤疎→終盤一斉。ビルドアップ標準形（実装例）
2. **減速カスケード（^3版）** — `hash^3` で前寄せ＝最初にドバッと落ちて最後は1灯ずつ。「もう残ってない」の絶望型。アウトロ向き
3. **方向性消灯（ワイプ型）** — `off = T0 + L * (x / COLS) + jitter*hash` ＝左から右／奥から手前へ順に落ちる。停電が「伝播する」物理感が出る
4. **中心残し（ヴィネット型）** — 中心からの距離で `off` を決め、外周から内側へ消す。最後に1点だけ残して落とす＝視線を強制収束
5. **段階復帰（Progressive Power-On）** — 同じ分布を逆再生。全暗から灯が1個ずつ戻る＝ドロップやラスサビ頭の「復活」に使える（消灯とペアで曲を挟む）
6. **窓形状消灯（3DCG／高品質版）** — 矩形セルでなく実際の窓・看板の emissive を個別に落とす。グリッド感が完全に消える最上位形
7. **不規則ちらつき付き** — 消灯の直前0.3秒だけそのセルを2〜3回明滅させる（切れかけの蛍光灯）。生っぽさが出るが720セル分の負荷に注意
