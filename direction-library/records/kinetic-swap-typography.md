# 逐次入れ替えキネティックタイポ / Kinetic Swap Typography

## 概要
歌詞を**語（短い句）単位**に割り、**次の語が来た瞬間に前の語を退場アニメーションで追い出す**逐次モデル。出入りのアニメーションは辞書から毎ブロック抽選するので、同じ動きが続かず画面上の文字が絶えず入れ替わる。さらに**語の性質で被写体の前後を出し分ける**（短い/繰り返す語＝画面いっぱいで背面を貫通、長い語＝手前で確実に読ませる）。

## 主な用途
- サビ／ドロップの主役タイポ（1曲の見せ場）
- 静パートとの落差を作る「動」側
- タイトルコール
- 歌詞が短く反復の多い曲（colour bass / ハードコア / EDM）

## 演出内容

### 1. 区切りは「語」。行でまとめない
行単位で出すと1つの塊が数秒居座って動きが止まる。**空白区切りの短い句を1ブロック**にして、行の尺に等間隔で並べる。

### 2. 逐次入れ替え＝次の語の登場が前の語の退場開始
```
block[k].outAt = block[k+1].at
```
これだけで「絶え間なく入れ替わる」が成立する。同じ語が2回出る歌詞では、**1回目が追い出されて2回目が入ってくる**のが自動的に絵になる（反復のある歌詞ほど効く）。

### 3. 出入りは辞書から抽選する
入り/抜けを固定すると3回目で飽きる。辞書を持ってブロックごとに引く。正本実装＝`styles/_mv-kit/src/anim.ts`。

- **入り（例）**: 手前から奥へ退く / 右外から滑り込む / 下から突き上げ / 上から落下 / 横に潰れた状態から開く / 回転しながら着地
- **抜け（例）**: 左へ加速 / 右へ弾く / 上へ抜ける / カメラ手前へ突き抜ける / 奥へ吸い込まれる / 回転して弾ける / 横に潰れて消える

**約束**:
- 不透明度のフェードに頼らない（実測でも出入りはフェードせず動きと変形で見せている）
- 移動量は**グリフサイズの倍数**で書く。px 直書きは 9:16 や級数違いで破綻する
- blur は出入りの2〜3フレームぶんだけ。掛けすぎると滲んで読めない
- 抽選は seed 決定論にする（レンダーが再現しないと検品できない）

### 4. 前後の出し分け（これが無いと読めないか字幕になる）
全部背面＝被写体に食われて読めない。全部手前＝ただの字幕。**1つの treatment を被写体の前と後ろで2回描き**、語の性質でどちらに出すか決める。

| 種別 | 条件 | 置き方 |
|---|---|---|
| punch | 語幅が全角3文字ぶん以下、**または曲中で2回以上出る語** | 画面いっぱい・中央・**背面**。被写体に食われてよい（反復するので読める） |
| read | それ以外 | 中サイズ・**手前**・被写体を避けた側に置いて確実に読ませる |

punch のサイズは**語幅から逆算**する。固定サイズだと長い語が画面幅を超え、中央を被写体に食われて両端しか見えなくなる。同時に出す punch は1つだけ（2つ重なると潰れる）。

### 5. 塗りは単色ベタ。縁・落ち影・グローを足さない
**白＋太い縁＋落ち影＋グローはカラオケ字幕の署名。** 背景と競合しない1色を決めてベタで置く。極彩色背景では白は原理的に沈むので、縁で無理に分離させようとして必ずダサくなる。

例外は2つだけ:
- **手前にいる間の落ち影**（入りの最中だけ落ちて、奥に退くと消える＝奥行きの手がかり）
- 手前レイヤーに出す read 語の**薄い分離影**（被写体から浮かせて読ませるため）

### 6. 級数は画面高で持つ
`vw` ではなく**画面高に対する%**で持つ。16:9 と 9:16 で文字の見え方を揃えるため。

### 実写 / アニメ / イラスト / 3DCG の差
- **イラスト/アニメ**: 被写体の切り抜き（またはレイヤー分離済みの素材）が要る。背面レイヤーが作れないとこの演出は成立しない
- **3DCG**: Zバッファがあるので板ポリで置けば前後は自動
- **実写**: 髪・煙で切り抜きが破綻する。破綻する箇所に read 語を置かない構図にする

## カメラワーク
- 歌詞を**カメラ変形の内側**に入れる。外に置くと固定オーバーレイ＝字幕になる
- カメラは静かなドリフトで足りる。動くのは文字

## 編集
- 一掃はハードカット（1フレーム）。フェードしない
- セクション境界で treatment を切り替えて静↔動の落差を作る

## 色
- **メインカラー:** 背景と競合しない1色（例: ゴールデンイエロー系 / 黒 / アイボリー）
- **アクセントカラー:** ラストサビ昇格用に1色（白発光＋虹縁など）
- **相性の良い配色:** 4色以内。文字は1色に決め切る

## ライティング
- なし（文字はフラット）。背面に回した語は被写体のリムライトで縁が拾われる

## リリックとの相性
★5 — この演出のための型。ただし**反復と短い語が多い歌詞**でこそ効く。長文の説明的な歌詞は read 側に溜まって動きが死ぬ。

## AI画像生成で再現する場合
- 生成側の仕事は「切り抜きやすい素材」と「文字を置く余白」を作ること
- **共通キーワード:** `subject clearly separated from background`, `negative space on one side`, `no text, no letters`
- 被写体が画面の4割を超えると背面の語が読めなくなる。**3割程度に収める**指示を入れる

## AI動画生成で再現する場合
- **重要要素:** 文字は絶対に生成させない（綴りが崩れ、フレーム間で形が変わる）。生成は被写体の微動と背景だけ
- **動画生成（providers.video）:** 被写体の微動ループだけを出す → 切り抜き → 文字レイヤーの前後に挟む

## 注意点
- **★塗りを盛った瞬間に終わる。** 縁・落ち影・グローを足すとカラオケ字幕になる
- **★全部背面にすると読めない。** 被写体が画面の4割を超える素材では特に。前後の出し分けが必須
- punch のサイズを固定すると長い語が両端しか見えなくなる。**語幅から逆算**する
- 衝突回避は**時間が重なる語同士だけ**で行う。時間の離れた語まで避けると配置が端に押し出される
- ラテン語は文字ごとに割らない（1塊にする）。割ると語が崩れて読めない
- 抽選に `Math.random()` を使わない。フレーム毎に再評価されて画がちらつく
- 語の滞留が短すぎると読めない。**文字数×0.085秒**を下回らないこと（lint で見る）

## 品質チェック
- 画面上の文字が**2秒以上同じ状態で止まっていない**か
- 同じ出入りアニメーションが3回連続していないか
- 被写体に食われて**一度も読めない語**が無いか（punch は反復語だけ）
- 文字に縁・落ち影・グローが付いていないか（入りの落ち影と read の分離影は例外）
- 16:9 と 9:16 で文字の相対サイズが揃っているか

## バリエーション
- **積もる型に切替**: outAt を次の語ではなくグループ終端にすると beat-word-stack になる（静かな曲向き）
- **1語だけ特大**: フレーズに1つだけ punch を仕込み、残りを read に回す（キメの作り方）
- **素材昇格**: 動きを一切変えず塗りだけ発光素材に差し替える＝ラストサビの「帰ってきた感」
- **方向を曲に合わせる**: 抜けの方向（左/右/上/奥/手前）を曲の推進方向に寄せて偏らせる
- **縦ショート版**: 級数を画面高%で持っているのでそのまま通る。read の配置だけ下寄せに変える
