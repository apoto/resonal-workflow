# 消失点ラッシュ / Vanishing Point Rush

## 概要
一点透視の風景（夜の道路・トンネル・廊下）の**消失点へ向かって7秒かけてじわじわ→終盤で一気に加速**して寄り、到達の瞬間に引いて次のセクションを開ける複合演出。背景の点滅を同じ進行度カーブで速くしていくことで「加速している」感覚を光でも重ねる。イントロ→歌い出しの導入に最も強い。

## 主な用途
- イントロ（クレジット表示区間）から歌い出しへの橋渡し
- ビルドアップ終盤の溜め＝到達点＝Drop/Aメロ頭に一致させる
- 「どこかへ向かっている」曲（帰り道・夜逃げ・追いかける・繰り返す日常）の視覚テーゼ提示
- キャラを消しながら寄る＝「街に溶けていく」孤独の提示
- 上下黒帯（レターボックス）を解除するタイミングを作る口実

## 使用頻度
A — 一点透視の背景が1枚あれば使える。イントロ導入の定番として曲頭に1回。曲中で複数回やると「毎回どこかへ向かう」ノイズになる。

## 使用タイミング
- 曲開始〜歌い出し直前（実装例: 15.0〜22.0秒＝7秒）
- ビルドアップ最後の8〜16小節（到達点＝Drop頭）
- 間奏明けからラストサビへの再導入（尺は半分の3〜4秒に詰める）
- 到達点そのもの（実装例: 22.0〜23.2秒の引き戻し）

## 演出内容
実装確定値（Remotion / 30fps / 1920×1080）。

- **溜め区間 7秒**（15.0〜22.0秒）。進行度 `p = (t - 15) / 7`（0→1）に対して
  `scale = 1.04 + Math.pow(p, 3) * 0.48` ＝ 1.04倍 → 約**1.52倍**。
  - **`p^3`（キューブ）がキモ。** p=0.5 時点でまだ `1.04 + 0.06 = 1.10` しか寄っておらず、残り半分で一気に来る。`p^1`（等速）は溜めが出ずただのゆっくりズーム、`p^2` でも前半が動きすぎる。
  - **倍率を上げすぎると酔う。** 約2.6倍は視聴が辛い。約1.6倍（実装 1.52倍）の「軽いズーム」に留める。1920幅の素材で1.5〜1.6倍が上限の目安。
- **`transformOrigin: '50% 70%'`＝画面の下寄り。** 消失点は「濡れた路面の奥」にあるので原点も下に置く。中央（50% 50%）や '50% 53%' だと空・街の上部へ寄ってしまい、目指す場所が上すぎて間延びする。**寄る先は必ず絵の消失点に合わせる**のが本演出の一丁目一番地。
- **溜め区間の直前は同じ scale / origin で据える。** 実装では `t < 15` を `scale(1.04) / '50% 70%'` の完全固定にしてある。始点を一致させないと 15.0 秒でカクッと段差が出る（カット再トリガーの微ブレも同時に排除した）。
- **点滅を同じ進行度でランプ（光でも加速を重ねる）:**
  - 周波数 `freq = 0.35 + Math.pow(p, 2) * 3.4`（rad/frame。遅い→速い）
  - 明滅強度 `flkStr = 0.25 + p * 0.9`（終盤ほど強い）
  - 波形は2波重ね `flicker = Math.sin(frame*freq)*0.7 + Math.sin(frame*freq*2.3 + 1)*0.3`（単一 sin だと機械的なストロボになる）
  - 出力先は3つ: 明度 `brightness(1 + |flicker| * 0.14 * (flkStr/0.5))` / 彩度 `saturate(1 + 0.24 + flicker*0.14*flkStr)` / 色相 `hue-rotate(flicker * 9deg)`。**明度だけ振ると安っぽい**。彩度と色相を薄く連動させるとネオンが「生きて明滅している」質感になる。
  - さらに `radial-gradient(120% 90% at 50% 45%, rgba(120,220,255,.5), rgba(255,80,220,.25) 45%, transparent 72%)` を `mix-blend-mode: screen` で `opacity = 0.1 + |flicker| * 0.08 * (flkStr/0.5)` で重ね、明滅を画面全体のグロウに波及させる。
- **到達点で引く（これが要点）:** 22.0〜23.2秒に `scale 1.34 → 1.06` を **0.4秒**（22.0→22.4、以降23.2までホールド）で戻す。`transformOrigin` は `'58% 40%'` へ切り替え＝原点も上げて「全景に戻る」。歌い出しと同時にカメラが「バーン」と登場する。**寄りっぱなしで終わらせないのが本演出の定義**（溜めを解放して次のセクションを開ける）。1.52 で終わった溜めを 1.34 から引き始めるので、到達フレームで意図的に不連続＝打点になる。
- **同区間でキャラ（後ろ姿）を 15.0〜20.0秒でフェードアウト**（opacity 1→0）。20〜22秒は不在。22.0秒で `opacity 0→1`（0.25秒）＋ `scale 1.32→1.0`（0.35秒）でバーンと再登場。**寄りと消失を同時に起こす**ことで「街に溶けていく」＝主体が消えて世界だけが加速する。
- **上下の黒帯（レターボックス、上下15%のインセット）は歌い出しの22.0秒まで維持**し、開けるタイミングを到達点に一致させる。溜め＝シネスコ、到達＝フル画面、という画面比の変化が到達感を二重化する。
- **実写:** ドリーで消失点へ直進。等速で撮ってタイムリマップ（後半を詰める）で `p^3` を作る。カメラの物理加速では終盤の詰めが出ない。
- **アニメ/イラスト（1枚絵）:** 上記の CSS/Remotion 実装がそのまま最適解。**多層にせず1枚のスケールで良い**のが本演出の利点＝一点透視の絵は元から奥行きを持っているので、マルチプレーン視差を足すと逆に路面の反射が破綻する。
- **3DCG:** カメラの Z 前進で消失点へ。FOV は固定（Dolly Zoom にしない）。廊下/トンネルなら壁の光源を等間隔に並べ、通過レートが上がることで加速が自明になる。

## カメラワーク
- Push In（加速・`p^3`）— 溜め区間の本体
- Pull Out（0.4秒の急な引き）— 到達点
- 原点オフセット付きズーム（`transformOrigin` を絵の消失点へ）
- 併用しないもの: パン・チルト・ロール（消失点へのベクトルが濁る。溜め区間は**一方向のみ**）

## 編集
- 到達点でレターボックス解除＋キャラ再登場＋歌詞1行目を**同一フレームに揃える**（3つ揃って初めて「開いた」になる）
- 溜め区間中はカットを割らない（7秒ワンカット）。割ると溜めがリセットされる
- 到達点の引きは Smash Cut で代替も可（引かずに次カットへぶった切る）。ただし解放感は落ちる
- Speed Ramp は不要（`p^3` が既に速度ランプ）

## 色
- **メインカラー:** 深い夜の紫〜藍（実装背景 `#05010f`）。消失点の奥だけ明るく残す
- **アクセントカラー:** シアン `rgba(120,220,255)` ＋ マゼンタ `rgba(255,80,220)`。両側のネオン＝この2色で挟む
- **相性の良い配色:** 濡れた路面の反射でアクセント2色が縦に伸びる配色。溜め区間で彩度を +24%、色相を ±9° 揺らして「近づくほど光が濃い」を作る。到達点で彩度を元に戻す（振り切ったままにしない）

## リリックとの相性
★★★☆☆ — **溜め区間は歌詞を出さない**のが正解（画面全体が動き続け、終盤は点滅が暴れるので読めない）。イントロのクレジット表示くらいまで。真価は到達点で、引き戻しと同時に歌い出し1行目を出すと文字が「バーン」と乗る。文字は必ずカメラの外＝固定オーバーレイに置く（ズームに巻き込むと歌詞まで1.5倍になって破綻する）。

## AI画像生成で再現する場合
**背景1枚の出来がこの演出の9割**。一点透視の消失点がはっきりある絵を作ることに全力を注ぐ。
- **共通キーワード:** one-point perspective, strong vanishing point at center, wet asphalt reflections, neon signs on both sides receding into distance, converging perspective lines, night city street, low camera height, deep depth, symmetrical composition, cyan and magenta neon
- **画像生成（providers.image）:** 「All lines converge to a single bright vanishing point slightly below the horizontal center of the frame」と**「消失点は画面中央よりやや下」を文章で明示**すると `transformOrigin: '50% 70%'` と噛み合う絵が出る。避けたい要素は fisheye / tilted horizon / birds eye view / cluttered foreground
- **生成後の必須チェック:** 消失点が画面の縦方向どこにあるか目視で測り、その座標を `transformOrigin` に入れる（絵に合わせて原点を決める。原点に絵を合わせようとしない）
- **上下15%が黒帯で隠れる前提**なので、消失点は上下15%の内側（縦16〜84%）に置く。上に寄りすぎた絵は使えない

## AI動画生成で再現する場合
**カメラ移動をAIに任せない。静止素材を生成し、ズームは後段（Remotion / 編集）で作る。** 理由: 7秒の加速ズームは AI 動画の破綻ゾーンで、①寄るほど路面の反射やネオン文字が別物に化ける ②5秒制限で7秒が撮れない ③`p^3` の非線形カーブを指定できない ④到達点の0.4秒の引きが表現できない。後段でやれば曲線も倍率もフレーム単位で調整できる。
- **重要要素:** ①**静止画（または微動ループ）を4K相当で生成** → 1.6倍に寄せても画質が保つ ②消失点を画面中央やや下に固定 ③カメラは完全固定で生成（`static camera, locked off`）④点滅は生成に含めず後段のフィルタでやる（AIの明滅は周波数を制御できない）
- **動画生成（providers.video）:** 背景1枚を起点に、カメラ移動の指定は使わず `static locked-off camera, only the neon signs flicker gently and light reflections shimmer on the wet road` ＝**環境の微動だけ**のループ素材を作る。生成側のズーム/ドリーは等速でしか出ず `p^3` の溜めが作れない＝**静止生成＋後段ズームが正解**
- **後段実装（Remotion）:** 背景 `<Img>` を `width/height 130%, top/left -15%` でオーバースキャンし、親 `AbsoluteFill` に `transform: scale(s)` / `transformOrigin` を当てる。オーバースキャンしておかないと寄る過程で端が見える

## 注意点
- **原点を絵に合わせる。絵を原点に合わせようとしない。** `'50% 53%'` では街の上部（空）へ寄ってしまう。背景を差し替えたら毎回 `transformOrigin` を測り直す
- **倍率の欲張りは酔いに直結。** 約2.6倍は酔い、約1.6倍で成立する。7秒級の長い区間ほど上限は低い（短尺2秒なら2倍も可）
- **等速（`p^1`）にすると溜めが消える。** 「じわじわ→ガッと」は `p^3` が作っている。逆に `p^5` 以上にすると前半が完全静止に見えて「壊れている」と誤解される
- **溜め区間の始点と直前の固定ショットで scale/origin を一致させる。** 不一致だと開始フレームで段差が出る（+ カット再トリガー由来の微ブレが混ざると事故る）
- **背景はオーバースキャン（130%配置）しておく。** 素の100%で寄ると端が見える前に寄れなくなる
- **30fps では点滅の上限に注意。** `freq` は rad/frame なので π（≒3.14）を超えるとナイキストを割ってエイリアシングし、規則的な高速点滅ではなく不規則な暴れになる。実装の終端値 3.75 rad/frame はこの領域＝「ガッと壊れる」質感を意図的に使っているが、**規則的な高速ストロボが欲しいなら 2.5 rad/frame 以下に抑える**
- **点滅を明度だけで振らない。** 彩度・色相を薄く連動（+24% / ±9°）させて初めてネオンに見える
- **寄りっぱなしで終わらせない。** 到達点で引かないと「途中で切れた」感になる。次のセクションを開ける動作までがワンセット
- **曲中2回以上やらない。** 「向かう」が繰り返されると目的地の重みが消える

## 品質チェック
- 寄り先（`transformOrigin`）が背景の絵の消失点と一致しているか。7秒後のフレームを止めて、画面中心が路面の奥（空や建物の上部でない）に来ているか
- 3.5秒（p=0.5）の時点でまだほとんど寄っていないか（scale 1.10 程度）。半分で半分寄っていたら等速になっている
- 到達点（22.0秒）で引きに戻っているか。寄り切ったまま次セクションに入っていないか
- 点滅の速さが単調増加になっているか（区間の 1/4・1/2・3/4 のフレームを比較して明滅間隔が詰まっているか）
- 到達点で「レターボックス解除 / キャラ再登場 / 歌詞1行目」が同一フレームに揃っているか

## バリエーション
- **トンネルラッシュ:** 消失点＝トンネル出口の白。等間隔の照明が通過レートで加速を自明にする。到達点で出口の光に白飛び（bloom-overexposure）してから引く
- **廊下ラッシュ:** 学校/病院/オフィスの廊下。消失点＝突き当たりのドアや窓。無人＋蛍光灯の明滅ランプで不気味側に振れる（`flkStr` の上限を 1.5 まで上げる）
- **線路ラッシュ:** レール2本が透視線そのもの。原点は最も下（`'50% 78%'` 程度）＝枕木の連続で速度が読める。夕方の逆光と相性が良い
- **ハイウェイラッシュ:** 中央分離帯とテールランプの列。消失点は高めなので原点は `'50% 60%'` 前後。溜め区間を4秒に詰めて BPM 150+ の曲に合わせる
- **階段ラッシュ:** 見上げ or 見下ろしの階段。消失点が上/下に極端に寄るので原点も `'50% 20%'` / `'50% 88%'` へ。到達点の引きで「高さ」が一気に開示される
- **アーケードラッシュ:** 商店街の連続アーチ。天井の連続構造がフレームを刻むので、点滅を構造の通過に合わせると加速が二重化する
- **逆走ラッシュ（Vanishing Point Retreat）:** 同じカーブで `p^3` の引き（消失点から離れる）。到達点で寄る。別れ・置き去りの導入に使う
