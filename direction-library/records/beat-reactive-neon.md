# ビート連動ネオン / Beat-Reactive Neon

## 概要
ネオン街や発光看板の画に対し、**輝度・彩度・色相を拍に同期して連続的に揺らす時間軸レイヤー**。素材は静止画1枚のままで、`filter: saturate() brightness() hue-rotate()` を1本掛けるだけで「街そのものが音に乗って呼吸している」ように見える。点滅で動きを分断するのではなく、**光の呼吸で曲のノリを画に乗せる**のが本質。

## 主な用途
- サビ/Drop で背景全体を音圧に同調させる（カット追加ゼロで熱量を上げる）
- 静止画背景（AI生成のネオン街1枚）を「動いている映像」に格上げする
- 間奏の無人カットに生命感を与える（キャラが居なくても画が死なない）
- ビルドアップで明滅の**周波数自体を加速**させ、加速感を光で作る
- 落ちサビ前のカラードレイン（彩度抜き）→復帰で「色が戻る」カタルシスを作る

## 使用頻度
A — ネオン/夜景系の画を持つ曲ならほぼ常用。ただし**常時掛けると効果が死ぬ**ため、曲尺の30〜40%程度に限定して使う道具。

## 使用タイミング
- ビルドアップ（周波数ランプで加速。例: 15〜22秒の7秒間）
- ドロップ/サビ（一定強度のチカチカを常灯。例: 61〜90秒、91〜98秒）
- 間奏の盛り上がり（例: 125〜138秒）
- ラストサビ（例: 151〜176.5秒。冒頭サビと同型を再演して回収）
- 落ちサビ直前（彩度を落として溜め → 復帰で開放）

## 演出内容
以下の数値は実装例（BPM150.10 / 30fps / 全尺197.88秒）の実測・確定値。

### 1. 掛けるのはフィルタ1本だけ
背景レイヤー全体に
```
filter: saturate(S) brightness(B) hue-rotate(H deg)
```
を掛ける。素材は静止画（`bg_neon.png`）で、スクロール `translateX(90px → -90px)` と緩いズーム `scale(1.0 → 1.04)`（0〜14秒）だけ別に持たせる。**素材を作り直さない**のが最大の利点。

### 2. 拍の位相は耳合わせでなく実測する
- `BEAT_SEC = 60 / BPM`。BPM150 なら **0.4秒/拍 = 2.5Hz**
- 曲頭のダウンビートは 0 秒ではない。**音源から実測してオフセットに入れる**（実例では `BEAT_OFFSET = 0.353秒`）
- 位相関数: `beatPhase(t) = ((t - 0.353) mod 0.4) / 0.4`（0=打点、1直前=拍の終端）
- ここを1フレーム(33ms)ズラすと「音より先に光る」ため全部が嘘になる。ffmpeg/aubio 等でオンセットを測る

### 3. beatFlash（拍頭のアタック）＝鋸波
```
beatFlash = max(0, 1 - beatPhase * 3)
```
拍頭で 1、**拍の1/3（BPM150で0.133秒＝30fpsで4フレーム）で 0** に落ちる鋸波。これを輝度に **+0.16** 分足す。キックの立ち上がりに光がぶつかる感触が出る。

### 4. flicker（不規則なチラつき）＝非整数倍の3波重ね
```
flicker = sin(f*0.9)*0.5 + sin(f*2.1 + 1)*0.3 + sin(f*0.37)*0.2
```
（`f` = フレーム番号。30fps 換算で約 4.3Hz / 10.0Hz / 1.8Hz の3成分）
- **周期を非整数倍にするのが自然さの分かれ目。** 単一の sin だと周期が読めて「機械が点滅している」に落ちる。2.1 / 0.9 = 2.333…、0.37 が絶対に割り切れないおかげで**うなり**が発生し、実在の劣化した蛍光管/ネオン管のランダムさに寄る
- 位相オフセット `+1`（第2波）も揃わないための仕込み。全波の位相を0で揃えると拍頭でだけ全部一致して不自然な同期点が出る

### 5. 合成値（この比率を守る）
```
brightness = 1 + beatFlash*0.16 + |flicker|*0.14
saturate   = 1 + 0.24 + flicker*0.14
hue-rotate = flicker * 9deg
```
- 輝度は**拍のアタック16% + 揺らぎ14%**の二階建て。片方だけだと「メトロノーム」か「ただのノイズ」になる
- 彩度は**常時+0.24を底上げ**した上で±0.14揺らす。底上げが無いと拍で暗部が沈むだけで発光感が出ない
- **hue-rotate は ±9度が上限。** これ以上振るとシアン `#00F0FF` が青緑や水色に化け、ブランドカラー（曲のキーカラー）が別物になる。9度は「同じ色のまま温度が揺れている」に見える限界値

### 6. グロー重ね（発光の滲み）
フィルタだけでは「明るくなる」に留まる。上に1枚重ねる:
```
mixBlendMode: 'screen'
background: radial-gradient(120% 90% at 50% 45%,
  rgba(120,220,255,0.5), rgba(255,80,220,0.25) 45%, transparent 72%)
opacity = 0.1 + beatFlash*0.16 + |flicker|*0.08
```
中心シアン→マゼンタ→透明の巨大グラデを `screen` で乗せる。これで**光が画面の外へ滲み出す**（＝発光体らしさ）。`opacity` に底値 0.1 を置くのは、拍の谷でグローが完全に消えると「レイヤーが点いたり消えたり」して見えるため。

### 7. 適用区間を必ず限定する
実例の適用区間は **15-22 / 61-90 / 91-98 / 125-138 / 151-176.5 秒**（合計約78秒＝全尺197.88秒の約40%）。
```
flickerZone(t) = (61≤t<90) || (91≤t<98) || (151≤t<176.5) || (15≤t<22) || (125≤t<138)
```
- **常時掛けると効果が死ぬ。** Aメロ・Bメロ・アウトロはフィルタを外し（`brightness=1, saturate=sat, hue=0`）、静かな区間との落差で「サビで街が起きた」を作る
- 区間の切り替えは1フレームで硬く入れて構わない（拍頭に合わせれば段差は音に隠れる）

### 8. カラードレインと組み合わせる（溜め→開放）
別系統の `sat` を掛け算で合流させる（`saturate(sat * chSat)`）:
- **136 → 139秒: `sat` を `1 → 0.12` に落とす**（3秒で色が抜ける＝落ちサビ前の溜め）
- 139 → 144秒: 0.12 で保持（ほぼモノクロの街）
- **144 → 149秒: `0.12 → 1` に戻す**（虹バーストと同時に色が戻る）
「揺らぎ」は続いているのに色だけ抜けるので、**動いているのに死んでいる街**になる。復帰時のカタルシスが最大化する。

### 9. ビルドアップは周波数自体をランプする
15〜22秒（7秒）で `p = (t-15)/7` として:
```
freq  = 0.35 + p^2 * 3.4    // rad/frame。遅い→速い（p^2 で後半一気に）
flicker = sin(f*freq)*0.7 + sin(f*freq*2.3 + 1)*0.3
強度   = 0.25 + p*0.9        // 最後ほど深い明滅
```
振幅ではなく**周波数を上げる**のが加速感の正体。`p^2` の二乗カーブで「じわ→ガッと」になる（線形だと均一に速くなるだけで煽られない）。※終端の輝度スイングが安全域を超えるので上限を掛ける（→注意点）。

### 媒体別
- **実写:** 撮影は定常光で押さえ、DaVinci でノードに Gain/Saturation のキーフレーム（またはExpression）を打つ。実照明で揺らすとNG時に取り返せない
- **アニメ/イラスト:** 発光レイヤーの不透明度＋全体の色調補正で同じ式を再現。線画レイヤーには掛けない（線が明滅すると絵が汚れる）
- **3DCG:** emissive intensity と Bloom の threshold を同式で駆動。カメラ露出（ToneMapping）側で揺らすと画全体が一体で呼吸する
- **Remotion:** 上記そのまま。`useCurrentFrame()` を式に入れるだけで完全に決定論的＝レンダー毎に同じ結果になる（実写のフリッカーと違い再現性が担保される）

## カメラワーク
- なし（固定 or ごく緩いスクロール/ズーム）。光が動く演出なのでカメラは静かにする
- 併用するなら push-in をサビ全体に緩く（`scale 1.0 → 1.04` 程度・14秒かけて）
- 速いカメラ移動と併用すると、点光源の移動＋輝度変調が二重になり画面が読めなくなる

## 編集
- カットしない。**カット割りの代わりに照明だけ変える**のが今風（照明チェンジ＝擬似カット）
- 区間の入り/抜けを拍頭にスナップさせる（フェードで入れない。段差は音でマスクされる）
- flash-cut / zoom-punch を「特に強い拍」だけに重ねる（毎拍やると磨耗する）
- カラードレイン区間の出口に light-flood-wipe を置くと色の復帰が事件になる

## 色
- **メインカラー:** シアン `#00F0FF` / `rgba(120,220,255,·)` × マゼンタ `#FF0090` / `rgba(255,80,220,·)`、暗部 `#05010F`
- **アクセントカラー:** グリーン `#39FF88`（毒・電脳）、オレンジ `#FF9E2C`（ナトリウム灯）
- **相性の良い配色:** 元素材が高彩度・高発光であること。`hue-rotate ±9度` は元の色を「揺らす」だけで**色を作れない**＝素材側の配色が全て。暗部が締まった（平均輝度25〜35%）素材でないと、明るくした瞬間に白濁する

## ライティング
- Neon / Practical Light（画面内の発光体が光源）を前提とする上乗せレイヤー
- Bloom / Glow（`screen` 合成のグローが本体の半分）
- Back Light 的な滲み（グローの中心を被写体の背後 `50% 45%` に置くと逆光の呼吸になる）

## リリックとの相性
★★★★☆ — 背景だけが呼吸し、文字は静止しているので**歌詞は完全に読める**（strobe-light と決定的に違う点）。ただし条件が2つ:
1. **文字レイヤーにフィルタを掛けない。** 背景レイヤーだけに掛ける（DOM/コンポジット順で分離）。文字まで彩度が揺れると滲んで読めない
2. 文字色は白＋グロー固定。背景が ±9度で色相を振るため、有彩色の文字は「たまに背景と同色になる」瞬間が生まれる

## AI画像生成で再現する場合
狙うのは**「後段で揺らす前提の素材」＝発光が強く彩度が高いネオン街、濡れた路面の反射あり、暗部が締まっている静止画1枚**。動きも明滅もAIに求めない。
- **共通キーワード:** neon-lit night city, glowing signage, wet asphalt reflections, high saturation, dark crushed shadows, no people, static wide shot
- **画像生成（providers.image）:** `night city street, glowing neon signs, cyan and magenta, wet reflective asphalt, deep dark shadows, high contrast, no white light, wide shot`。「the only light sources are the neon signs themselves」と**光源が画面内にある**ことを文章で明記し、彩度が盛られやすいので `muted shadows` で暗部を締める。避ける語: daylight, flat lighting, washed out, low contrast, motion blur

### 素材側の必須条件（これを満たさないと後段が効かない）
1. **発光体が画面内に複数ある**（看板・窓・テールランプ）。反射光だけの画は輝度を上げても「明るくなった」だけで発光しない
2. **濡れた路面/ガラス/水面の反射がある**（実質的な発光面積が2倍になり、揺らぎの見え面積が稼げる）
3. **暗部が締まっている**（`brightness` を最大 +30% するので、元が明るいと確実に白飛びする）
4. **解像度は最終尺の1.3倍以上**（スクロール/ズーム用の余白。実装では `width/height: 130%` で `-15%` オフセットして使う）
5. **人物は入れない**か、キャラは別レイヤーにする（フィルタが人物の肌色を破壊する）

## AI動画生成で再現する場合
- **重要要素:** **AIに点滅を任せない。** 明滅を指示するとフレーム間でちらつきが制御不能になり、拍と一切合わない上に強度も一定しない（フレーム補間で均されるか、逆に破綻したパカつきになる）。**素材は静止（または極低速の環境モーションのみ）、揺らぎは後段で数式的に付ける**が唯一の正解。式で作れば1フレーム単位で拍に合い、レンダーの再現性もある
- **動画生成（providers.video）:** 静止ネオン街を画像から動画化し、動きは `very slow camera push in, steam rising, subtle atmospheric motion only` 程度に限定。`flickering` `blinking` `strobe` は書かず、`no flicker, steady lights` と否定形で明滅を禁じる。Hz制御は必ず編集/コード側

## 注意点
- **【必須】光過敏性発作（PSE）への配慮。** 明滅を含む演出なので安全設計が制作要件に入る:
  - **拍同期のアタック（beatFlash）は3Hz以下に収める。** 4分打ちなら BPM180 までが 3.0Hz で適合（BPM150=2.5Hz、BPM128=2.13Hz）。BPM180超は**2拍ごと**に落とす
  - **3Hzを超える成分（flicker の 4.3Hz / 10.0Hz 成分）は輝度スイングを20%以下に抑える。** 実装の `|flicker|*0.14`（=最大14%）はこの制約から来た数値で、上げてよい余地はない
  - **ビルドアップの終端は要注意。** 周波数ランプ（最大約18Hz）で強度係数が 1.15 まで上がると輝度スイングが約32%に達し、20%基準を超える。**強度に上限を掛ける**（スイング20%相当でクリップ）か、ランプ区間を2秒以内に短縮すること
  - **鮮やかな赤の明滅を作らない。** `hue-rotate` でマゼンタが赤側に寄りすぎないよう ±9度を厳守
  - 規則的な明滅の連続は控え、静かな区間（フィルタOFF）を必ず挟む＝本演出の「区間限定」はそのまま安全設計になっている
  - YouTube等に出す場合は概要欄に点滅注意を書く
- **`frame` を式に入れると fps 依存になる。** `sin(frame*0.9)` は30fpsで約4.3Hz だが、60fpsで書き出すと**倍速の8.6Hz になる**。fps を変える予定があるなら `sin(t*27)`（秒基準）に書き換える。ここは実装上いちばん踏む罠
- **文字・キャラレイヤーにフィルタを掛けない。** 背景レイヤーだけに閉じる。掛かると肌色が破壊され、文字が滲む
- **常時適用は禁止。** 全尺に掛けると3秒で目が慣れて「ただ彩度の高い動画」になる。曲尺の30〜40%まで
- **数値を盛りたくなるのを我慢する。** `brightness +0.16/+0.14`、`hue ±9度` を倍にすると一瞬で「安いプリセット」の見た目になる。効かせたい時は**静かな区間を静かにする**方向で落差を作る
- 高彩度＋輝度変調はグラデーション部にバンディング（縞）が出やすい。film-grain を薄く（opacity 3〜6%）常時乗せて潰す
- 拍位相のズレは**必ず音源から測る**。耳合わせで「合っている気がする」は1〜2フレームズレている

## 品質チェック
- [ ] **拍頭と輝度ピークが1フレーム以内で合っているか**（サビ頭を1フレームずつ送って、キックのフレームで最も明るいか確認）
- [ ] **静かな区間（Aメロ/アウトロ）でフィルタが完全に切れているか**（`brightness=1 / hue=0` になっているか。区間の入り抜けフレームを実測）
- [ ] **揺らぎに読める周期が無いか**（10秒連続で見て「タッタッタ」と拍子が読めたら単一sin化している＝3波の非整数比が壊れている）
- [ ] **輝度ピークのフレームで白飛び（255クリップ）していないか**（看板の中心が真っ白な面になっていないか。特にビルドアップ終端）
- [ ] **文字・キャラの色が背景と一緒に揺れていないか**（歌詞の白が拍でピンクに転んでいたらレイヤー分離が失敗している）

## バリエーション
- **拍アタック型（標準）:** `beatFlash` 鋸波 +0.16 と 3波flicker +0.14 の二階建て。サビ/Drop の常用形
- **周波数ランプ型（ビルド用）:** `freq = 0.35 + p²*3.4` で明滅を加速。7秒程度のビルドアップ専用（安全上限のクリップ必須）
- **カラードレイン合流型:** 揺らぎは維持したまま `saturate` を 3秒で `1 → 0.12` に落とし、5秒で復帰。落ちサビ前の溜め→開放
- **色相ブリーズ型:** `brightness` を固定し `hue-rotate` だけを ±9度・0.5Hz 程度でゆっくり往復。Aメロ用の「静かに生きている街」
- **看板単体型:** 画面全体でなく看板要素だけを個別 div に切り出し、`hash01(k)` で各看板に異なる位相を与える。故障した看板が混じる実在感（劣化ネオンの表現）
- **2拍打ち型（高BPM対応）:** BPM180超の曲で `beatPhase` を2拍周期に落として3Hz以下を保つ。Phonk/ハードコア向け
- **反射面強調型:** グローの中心を路面側（`at 50% 75%`）に置き、濡れたアスファルトが呼吸しているように見せる。雨曲向け
