# 刷り出して残すタイポ / Wipe-In Persist Type

## 概要
歌詞を**進行方向のワイプで1文字ずつ「刷り出し」→ 数秒そのまま残す → 1フレームで一掃**する型。入れ替え続ける kinetic-swap-typography の対、**静側の主役**。文字が居座るので、動きは背景（パララックス・面の切替）が受け持つ。

出入りの実測値（参考MVのマスク面積をフレーム毎に追った結果）:

| 相 | 実測 |
|---|---|
| 立ち上がり | 面積 0 → 0.46% → 1.38%。**約0.3秒**で出切る（1フレームで全部出ない） |
| 滞留 | 約3秒。ゆっくり縮み、横に流れる |
| 消去 | **1フレームで面積0**（ハードカット。フェードしない） |
| キメ | 1フレームおきの点滅を数フレームだけ（2箇所で確認） |

## 演出内容

### 1. 1文字ずつ、進行方向にワイプする
`clip-path: inset()` を1文字ずつ時間差で開ける。横書きなら左→右、縦書きなら上→下。

```
1文字ぶんの間隔 = 出切る秒 / 文字数
1文字を出し切る時間 = 間隔 × 1.6   （隣と少し重なるほうが繋がって見える）
```

出切る秒は**0.3秒前後**。6文字なら1文字あたり1.5フレームで、ここに真の筆順アニメを入れる時間は無い。**速度がごまかすので方向ワイプで十分「書かれた」に読める。**

### 2. 出切ったあとは「ほぼ止まる」。ただし完全には止めない
滞留中に**ごくわずかに縮んで流れる**（3秒で0.1倍・画面幅の1%強）。止め切ると版に見え、動かしすぎると読みが乱れる。

### 3. 消去は1フレーム
セクションの終わりで消す。フェードアウトさせると余韻ではなく「終わり損ね」に見える。

### 4. キメの点滅は1フレームおき・数フレームだけ
`floor(frame) % 2` で出す/消すを交互に。0.2〜0.3秒で止める。長いとストロボになって読めない。

### 5. 書体は「重さ」で選ぶ。参照の書体をそのまま持ってこない
同じ級数でのインク占有率（実測・地別）:

| 書体 | 暗地/明字 | 明ベタ地/黒字 | 白地/明字 |
|---|---|---|---|
| Yuji Syuku（毛筆） | 13.9% | 9.1% | **8.3%** |
| Dela Gothic One | **31.8%** | 19.2% | 21.4% |
| Noto Sans JP 900 | 26.6% | 16.4% | 19.2% |
| Mochiy Pop One | 27.1% | 16.4% | 21.0% |

軽い書体は**明るい地で必ず負ける**。参照が筆文字でも、明るい面を持つ構成なら極太ゴシックに振り替える判断が要る。

**役割で2書体**に分けるのが安定:
- **display**（極大・短い語）＝最重量の書体。ただし CJK のサイドベアリングが狭いものは字間を足す
- **read**（長い行）＝display と同格の重さで字間が詰まらないもの

### 6. 塗りは単色ベタ。細く見えたら級数か地で直す
縁・落ち影・グローは足さない。細く見えるときの解は「級数を上げる」「地を締める」「書体を替える」の3つで、**装飾ではない**。

### 実写 / アニメ / イラスト / 3DCG の差
- **イラスト/アニメ**: そのまま通る
- **実写**: 地の明度が区間内で変わるので、塗りを1色に決め切れるカットを選ぶ
- **3DCG**: 板ポリに焼くと被写体の前後に置ける

## 注意点
- **★参照の書体をそのまま真似しない。** 明るい面を持つ構成では軽い書体（毛筆・細ゴシック）は必ず負ける
- **★空白の扱いを縦横で分ける。** 縦書きは空白を詰めるが、横書きで一律に除去すると `still here` が `stillhere` になる
- 字ごとに大きさを揺らして「手書きらしさ」を出そうとしない。**重いゴシックでベースラインが揺れると実装ミスに見える**
- `letterSpacing` は**最後の字の後ろにも入る**ので、中央寄せすると同じ幅だけ左にズレる（1920px 中40px 実測）。`marginRight` で打ち消す
- 滞留を短くしすぎない。**文字数×0.085秒**が下限
- 級数は px ではなく**画面高に対する%**で持つ（9:16 で破綻するため）

## 品質チェック
- 出切るまでが0.3秒前後に収まっているか（遅いと「打ち込み」に見える）
- 消去が1フレームで切れているか
- 文字に縁・落ち影・グローが付いていないか
- 縮小表示（サムネサイズ）でも読めるか
- 横書きで単語間の空白が残っているか
- 中央寄せした極大の語が本当に中央にあるか

## バリエーション
- **縦書きの柱**: 画面端に縦で置く。1フレーズ4〜6文字まで
- **丸ポップ体に差し替え**: 明るい曲では display / read の両方を丸ポップ体に。動きは変えない
- **極大の抜き文字**: ベタ面に1語だけ。出た直後にわずかに詰める（極太は動かないと版に見える）
- **入れ替え型へ切替**: 滞留を捨てて次の語で追い出すと kinetic-swap-typography になる
- **縦ショート版**: 級数を画面高%で持っているのでそのまま通る
