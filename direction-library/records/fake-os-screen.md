# 偽OS画面 / Fake OS Screen

## 概要
画面全体を架空のPCデスクトップに見立て、エラーポップアップ連打・チャットウィンドウ・ブルースクリーンなどOSのUIで物語る演出。「誰かの画面を覗いている」構造がネット文化・電波・狂気と直結する。感情の暴走をエラーの物量で、精神の崩壊をクラッシュで描ける。

## 主な用途
- エラーポップアップ連打で感情の暴走・思考のループを可視化（ビルドアップ〜Drop）
- チャット画面で歌詞を会話として進行させる（Aメロ・Bメロ）
- ブルースクリーン/クラッシュで曲の「壊れる瞬間」を作る（Drop頭・ラスサビ前の無音）
- デスクトップ全景＋カーソルの動きだけで主人公の心情を芝居させる
- ネット依存・承認欲求・裏アカ・晒しなどインターネット題材の曲の世界観そのもの

## 難易度

## 使用頻度
B — 電波・ネット文化系では強い定番。世界観を「PCの前の誰か」に固定するので採用判断は曲テーマ次第。

## 使用タイミング
- Aメロ（デスクトップ全景・チャット開始。カーソルの芝居で静かに導入）
- Bメロ（通知が増え始める。ウィンドウ2〜4枚）
- ビルドアップ（エラーポップアップ連打: 4fに1枚→終盤2fに1枚へ加速）
- ドロップ（画面崩壊・ブルースクリーン・再起動）
- 間奏（ファイル整理・ゴミ箱・履歴などの小芝居）
- ラストサビ（全ウィンドウが一斉に閉じて壁紙＝本心が見える、等の解放）

## 演出内容
- **エラーポップアップ連打:** ウィンドウ480×160px（タイトルバー28px、本文14〜16px、OK/キャンセルボタン88×26px）。1枚目を画面中央に出し、以降右下へ24px/18pxずつオフセットしてカスケード。出現間隔はビルド前半4f→終盤2fに加速、最終30〜60枚。出現音（ポーン）をハイハットに同期させると気持ちいい。
- **チャット画面:** 吹き出し・タイピングインジケータ（「…」8fごとに点滅）・既読表示。歌い出しの20〜30f前に「入力中…」を出してから吹き出しをポップ（scale 0.9→1.03→1.0を6f）。既読スルー＝無音、ブロック＝ブツ切りSmash Cutが定石。
- **ブルースクリーン:** 単色ベタ（#1D3FA8など「青系だが実在OSと違う色」）＋白等幅テキスト（16〜20px）＋エラーコード風の意味深な文字列（歌詞やタイトルを混ぜる）。表示は最低45f止めて読ませる。直前に1〜2fの黒を挟むと「落ちた」感が出る。
- **カーソルの芝居が最重要:** 等速直線移動は機械的。ease-in-out＋目標手前でのオーバーシュート2〜3px＋迷い（2回往復）で「人間が操作している」演技になる。ダブルクリックは2f間隔。
- **実写:** ①画面全体をOSにする（画面収録風・16:9フル）②実写内のモニターにコーナーピン合成して「部屋で見ている人」ごと撮る、の2択。②は孤独・生活感が加算される。
- **アニメ/イラスト:** キャラをウィンドウ内に住まわせる・壁紙にキャラ絵を敷く・エラーダイアログのアイコンをキャラ顔にする等、UIとキャラを融合できるのが強み。
- **3DCG:** モニターオブジェクトの画面テクスチャとして流し込み、カメラが画面に寄って全画面UIへ移行（実写→UIのシームレス転換）が作りやすい。

## カメラワーク
- なし（画面固定）が基本。OS画面は「カメラが存在しない」ことがリアリティ
- 例外: 画面の一部へのデジタルpush-in（ズーム）は「注視」の表現として有効
- モニター実写併用時のみ、push-in で画面に寄り切って全画面UIに切り替える

## 編集
- smash-cut: ブルースクリーン→無音→再起動で場面転換
- glitch-cut: ウィンドウ描画の乱れ・画面のちらつきとしてカットを繋ぐ
- flash-cut: 通知ラッシュの点滅と同期
- カット無しの長回し（画面録画風ワンテイク）も強い。生々しさが出る

## 色
- **メインカラー:** OSグレー（#D4D0C8系のレトロ灰色）または白背景＋黒文字。壁紙で世界観色を決める
- **アクセントカラー:** エラーレッド（#E81123系を微妙にずらす）、通知バッジ赤、既読グレー
- **相性の良い配色:** レトロOS灰×ピンク壁紙（電波・かわいい狂気）、黒背景×緑等幅（ハッカー・ダーク）

## ライティング
- 原則なし（UIはフラット。照明概念を持ち込まない方がOSらしい）
- モニター実写併用時: 画面光だけで顔を照らすモニターグロー（青白・下から）が「深夜のPC」の定番
- scanline-crt併用時のみ、画面全体に微ブルーム（強度10〜15%）

## リリックとの相性
★★★★★ — チャット吹き出し・エラーダイアログ本文・ファイル名・検索窓・ブルースクリーンのエラー文まで、歌詞の置き場所が無限にある。「歌詞をUIの文言として偽装する」こと自体がこの演出の本体。テンポの速い曲ではダイアログ本文は1行20文字以内に。

## AI画像生成で再現する場合
UIの文字・矩形の精密さはAI生成では出ない。AIは壁紙・ウィンドウ内の写真/イラスト素材の担当。
- **共通キーワード:** retro computer desktop, old OS interface, error message popup, glitchy screen, 90s PC aesthetic
- **画像生成（providers.image）:** 壁紙・ウィンドウ内素材・雰囲気ボードの生成に限定（例: nostalgic 90s computer wallpaper, teal sky, dithered gradient）。ダイアログの文字は必ず後からコードで描く

## AI動画生成で再現する場合
- **重要要素:** OS UIは矩形の直線性・文字の可読性・カーソルの意図が命。3つともAI動画は保証できないため、UIは100%コード/AE、AIは素材専門と割り切る
- **(a) 背景素材にプロンプトで乗せる方法の限界:** `error popup windows` と書いてもウィンドウは歪み、文字は崩れ、ボタンは溶ける。フレーム間でウィンドウ位置も揺れる。「壊れたPCの悪夢」のような抽象表現なら逆にアリだが、読ませる演出には使えない
- **(b) オーバーレイ合成の実装手順:** ①壁紙またはウィンドウ内で流す動画素材をAIで生成 ②OS UI（ウィンドウ・ダイアログ・カーソル・チャット）をHTML/CSS+JSまたはRemotion/AEで透過レンダ（連番PNG or ProRes 4444。カーソル芝居はキーフレームで打つ） ③Normal（アルファ）合成でUIを最前面に。ウィンドウ内にAI動画をはめる場合はUIレイヤーに開けた矩形穴へ下レイヤーを表示 ④馴染ませ: 全体に画面収録風の微ノイズ（不透明度3%）、必要ならscanline-crtを最上段に
- **UI描画は確定的なコード生成が向く。** 特にポップアップ連打の物量・出現タイミングの音同期は、HTML/CSSやRemotionでforループを書く方がAE手打ちより速く正確
- **動画生成（providers.video）:** ウィンドウ内素材（キャラループ・空・ノイズ映像）の生成用に限定し、UI無しを指定する。画面全体のOS生成は不可と考え、「computer screen with error messages」系は雰囲気カット1〜2秒の挿入用まで

## 注意点
- **実在ブランドUIの模倣に注意（最重要）。** 実在OSのロゴ・ドック・大手メッセンジャーの吹き出しUIそのままの再現は商標・不正競争・「そっくりデザイン」リスク。汎用化のコツ: ①配色を1〜2段ずらす（実在アプリの緑→ミント/紫）②角丸半径・ボタン配置・タイトルバーの閉じるボタン位置を変える ③架空のOS名/ロゴを作って画面に置く（架空OSであることを画面内で宣言する）④実在OSの標準フォントを避けDotGothic16・Inter等に差し替える
- **カーソルが等速直線だと一瞬で嘘になる。** ease＋オーバーシュート＋迷いの3点セットを必ず入れる
- ウィンドウ物量は「読ませる1枚＋飾りの群れ」に分ける。全部読ませようとすると視線が迷子
- ブルースクリーンは長く見せる（45f以上）。一瞬だと「読めなかったストレス」だけ残る
- 解像度の嘘に注意: 4K配信でドット絵風UIを出すなら整数倍拡大（ニアレストネイバー）。バイリニア拡大のぼけたピクセルは安っぽい

## 品質チェック
- 実在UIの模倣になっていない（架空の意匠に留めている）
- UIが飾りでなくイベント（押下/エラー/進行）を起こしている
- UI要素が歌詞の可読域を侵していない

## バリエーション
- **エラー連打カスケード型:** ビルドアップで加速する通知地獄→Dropでクラッシュ。物量の快感
- **チャット劇型:** 会話UIだけで1曲進行。既読スルー・ブロックをドラマの句読点にする
- **レトロ90s型:** 灰色UI＋ピクセルアイコン＋ディザ壁紙。ノスタルジー・電波かわいい
- **ホラー侵食型:** 正常なデスクトップが徐々に文字化け・黒ずみ・開けないファイルに侵食される
- **再起動リセット型:** ラスサビ前にクラッシュ→BIOS風起動画面→ラスサビで新しいデスクトップ（=生まれ変わり）
- **配信画面型:** 配信コメント欄・視聴者数・投げ銭風UIで承認欲求テーマを直撃する
