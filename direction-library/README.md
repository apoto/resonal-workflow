# 演出の辞書（direction-library）

MV に限らず、映像の「見せ方」を AI と相談するための辞書です。1演出＝1ファイル。AI（Claude Code / Codex など）が検索して、選んで、組み合わせて、実装に落とすことを前提に書いてあります。

- `INDEX.md` … 全レコードの一覧（カテゴリ / 難易度 / 頻度 / 感情 / 一行説明）。まずここから選ぶ
- `records/<slug>.md` … 演出レコード（カメラ・編集・光と色・エフェクト・文字・構図・動き・UI の原子）
- `situations/<slug>.md` … 場面レコード（場所×光×演出セット。演出セットは records/ の slug で組む）
- `_TEMPLATE.md` / `_TEMPLATE_SITUATION.md` … レコードを足すときの書式

## 使い方

1. 曲（映像）の区間ごとに、出したい感情とタイミングを決める（例: 「サビ頭で解放感」「Aメロは静かに孤独」）。
2. `INDEX.md` を感情・タイミングで絞り、候補を2〜3個選ぶ。場所から考えたいときは situations/ から入り、「演出セット」の slug で records/ に降りる。
3. レコードの「演出内容」「品質チェック」「相性の良い演出」「相性の悪い演出」を読んで組み合わせを決める。
4. 決めたものを `DIRECTION.md`（区間ごとの演出表）に slug で書き、AI に「この slug の演出内容どおりに実装して」と伝える。
5. レンダー後、レコードの「品質チェック」を YES/NO で確かめる。

MV で使う場合は skill `mv-styles` の18軸（`.claude/skills/mv-styles/references/axes.md`）と組み合わせる。軸が「どの引き出しを開けるか」、この辞書が「引き出しの中身」。

## 想定する問い

- 「サビで高揚感を出したい」→ INDEX で 感情=高揚 × タイミング=サビ/ドロップ を絞る
- 「この演出と組み合わせるなら」→ レコードの「相性の良い演出」を辿る
- 「動画生成で作りたい」→ レコードの「AI動画生成で再現する場合」＋「プロンプト例」を使う（使うサービスは `workflow.config.json` の `providers.video`）
- 「雨の夜の映像にしたい」→ situations/rain-street.md から入る

## レコードを足す・直す

1. `_TEMPLATE.md`（場面なら `_TEMPLATE_SITUATION.md`）を `records/<slug>.md`（`situations/<slug>.md`）にコピーして埋める。
2. `INDEX.md` の該当カテゴリに1行足す。
3. 「類似演出」「相性」欄の slug が records/ に実在することを確かめる。

既存のレコードは、使ってみて数値や品質チェックが合わなければ自分の実測で書き換えてよい。

書き方:


- frontmatter（YAML）に検索用メタデータ、本文に詳細。両方必須。書式は `_TEMPLATE.md`。
- 数値（尺・フレーム数・角度・色）まで書く。曖昧な形容で済ませない。
- 実写 / アニメ / イラスト / 3DCG で扱いが違えば分けて書く。
- 1レコードだけ読んで分かるように書く（他レコードへの参照は「類似演出」「相性」欄で）。
- slug は英語の kebab-case。足したら `INDEX.md` に1行足す。
- 他の人の作品名・アーティスト名は書かない。自分の作品での使用例は1行まで。

既存レコードの `RESONAL での使用例` 節は、RESONAL の公開済み MV で使ったときの1行メモです。自分で足すときは `自作での使用例` 節に書く。
