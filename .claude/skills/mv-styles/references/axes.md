# MV の18軸 — 品揃え＋シーン別上書きの記法（正本）

役割分担（二重管理しない）:
- このファイル … 18軸それぞれの品揃え（選択肢）と実装の当て先、シーン別上書きの記法。
- `direction-library/INDEX.md` … 各選択肢の中身（演出の辞書。何が起きるか・数値・相性・品質チェック）。軸の値を決めたら、該当するレコードを開いて実装の指示に使う。
- `songs/<曲フォルダ>/STYLE-SELECTION.md` … その曲の既定値（18軸を1値ずつ）。
- `songs/<曲フォルダ>/DIRECTION.md` の「シーン別の軸」節 … シーンごとの上書き（任意。シーンで軸を変えるときだけ作る）。

## 使い方（2段構え）

1. 曲の既定値: STYLE-SELECTION.md に18軸を1値ずつ書く。既定値は「この曲で一番多く使う値」。
2. シーンの上書き: DIRECTION.md の `## シーン別の軸` 節に、既定から変える軸だけをシーンごとに書く。

### シーン別の軸の記法

```markdown
## シーン別の軸（既定=STYLE-SELECTION.md・変える軸だけ書く）
| 区間 | シーン | 軸の上書き | 根拠・実装 |
|---|---|---|---|
| 0:12–0:34 | Aメロ | F4=下→上（縦チルト） / F3=明るく（ブルーム） / L3=右→左へ流し | 静の区間。カメラで持たせる |
| 0:57–1:22 | サビ | L1=キャラの背面 / C3=全身 / F3=粒子上昇 / H1=発火 | 歌い出しの語に合わせて切替 |
| 1:22–1:45 | 間奏 | C0=出さない / F2=小節頭でswap / F4=構図ジャンプ | 器楽区間を2〜4秒刻みで割る |
```

- 書式: `軸コード=値`。区切りは ` / `。
- 既定のままのシーンは行ごと省略してよい。全編既定なら「全編既定」＋理由を書く（黙って空にしない）。

## 各軸の品揃え

太字〔既定〕＝考える出発点。

### 歌詞（L軸）
| 軸 | 選択肢 | 実装の当て先・メモ |
|---|---|---|
| **L0 レイヤー構成** | **単層**〔既定〕／二層 | 二層（サビ/非サビで2セット）はシーン別上書きで書く |
| **L1 配置** | **中央**〔既定〕／画面いっぱい／左右の端（縦書き）／下帯・左下／散らし／キャラの背面／出さない | 背面＝文字を2回描き、片方を被写体の輪郭の外だけ見せる。余白を大きく取るなら被写体と反対側へ |
| **L2 書体** | **極太ゴシック（Noto Sans JP 900）**〔既定〕／明朝（Noto Serif JP）／丸ポップ／高コントラストセリフ／極太コンデンス | フォントは Google Fonts（OFL）を `@remotion/google-fonts` で読む。単一ウェイトの書体に `fontWeight: 900` を指定しない（合成太字で幅がズレる） |
| **L3 出入り** | **ハードカット**〔既定〕／跳ね出現／刷り出して残す／語単位で入れ替わる／フェード＋上昇／1文字スプリング／流し（方向指定）／積み上げ→一掃 | 語単位の入れ替えは「次の語の登場＝前の語の退場開始」で繋ぐ。抽選に `Math.random()` を使わない（フレームごとに再評価されてちらつく）。辞書: wipe-in-persist-type / kinetic-swap-typography / beat-word-stack / kinetic-typography |
| **L4 装飾** | **なし**〔既定〕／図形バースト／色収差／ネガポジ反転／縁＋グロー／グリッチ字 | 明るい地にグローは効かない＝縁で締める。辞書: rgb-split / negative-invert / glitch-text |
| **L5 帯（下スクリム）** | **なし**〔既定〕／区間中つけっぱなし／行ごと（非推奨＝チカチカする） | スクリムは energy 駆動にしてサビで外す（常時全開は顔が消える） |

### キャラ（C軸）— 動かし方はスタイルに焼き込まない（skill `bounce-rig` / `puppet-rig`）
| 軸 | 選択肢 | 実装の当て先・メモ |
|---|---|---|
| **C0 在否** | **出す**〔既定〕／出さない／シルエット | — |
| **C1 素材** | **静止1枚**〔既定・コスト0〕／表情差分つき静止／透過連番（動画生成）／動画素材（シーン限定） | コストの小さい順に検討する（静止 → 表情差分 → CSSリグ → 動画生成）。表情差分は `bounce-rig` の `face_swap.py` |
| **C2 動き** | **呼吸のみ（拍非同期）**〔既定〕／squash&stretch／関節リグ／連番再生／浮遊 | squash&stretch＝`bounce-rig`、関節＝`puppet-rig`、連番＝動画生成（`providers.video`）を透過連番にしたもの。辞書: breathing-idle / hair-cloth-sway / floating-levitate / keyed-character-composite |
| **C3 フレーミング** | **固定バストアップ**〔既定〕／全身固定／体を舐める／構図ジャンプ | 同一構図を8小節以上続けない。寄りの素材にカメラの寄りを重ねない（素材の占有率で拡大の上限を決める） |
| **C4 前景分離** | **しない**〔既定〕／fg+bg に割る | 写真背景は rembg、単色地（グリーン等）は色キー（`bounce-rig` の `greenkey.py`）。グリーンバックを rembg で抜かない |
| **C5 表情の切替** | **固定**〔既定〕／区間ごと／打点で一瞬（非推奨＝チラつく） | 切替は区間まるごと。歌い出しの語の秒に合わせる |

### 面／背景（F軸）
| 軸 | 選択肢 | 実装の当て先・メモ |
|---|---|---|
| **F1 素材** | **静止画（`tools/gen_image.sh`）**〔既定・コスト0〕／プロシージャル（コード）／動画（動画生成・`providers.video`）／3D空間（React Three Fiber）／キービジュアル1枚固定 | 雪・霧・粒子・光条・グレインはコードで作る。動画生成はコードで作れない動き（髪・水・面全体の質感変化）だけ |
| **F2 切替** | **切替なし**〔既定〕／小節頭でswap／セクションごと | 同じ面が隣り合う区間は、意図した継続以外は面を足す。既定の型では `scenes.json`（skill `music-video`「シーンの切り替え」）。辞書: flat-field-swap |
| **F3 画面エフェクト** | **常時うっすら1種**〔既定〕／なし／区間ごとに差し替え | 例: 色相シフト（color-shift）／ブルーム・露出オーバー（bloom-overexposure）／粒子上昇（particle-rise）／RGB ずれ（rgb-split）／フィルムグレイン（film-grain）／光条（god-rays）／ライトリーク（light-leak）／走査線（scanline-crt）／ビネット（vignette）。他は `direction-library/INDEX.md` の「エフェクト・タイポグラフィ」「ライティング・色彩」。面だけにトーンを掛け、全画面フィルタで文字まで染めない |
| **F4 カメラ** | **ゆっくり移動**〔既定〕／固定／構図ジャンプ／押し込み（push-in）／引き（pull-out）／縦チルト／周回（orbit）／ドリーズーム／ホイップパン／追従／真俯瞰／消失点へ突進 | 各選択肢は `direction-library/INDEX.md` の「カメラ」に1件ずつある（push-in / pull-out / orbit / dolly-zoom / whip-pan / tracking-follow / top-shot / vanishing-point-rush / cut-entry-drift 等）。カメラは3段ギア（静＝ドリフト／build＝加速する寄り／drop＝拍の打点）。画面全体を揺らすシェイク（camera-shake）は使うなら理由を書く |

### 打点（H軸）
| 軸 | 選択肢 | 実装の当て先・メモ |
|---|---|---|
| **H1 発火範囲** | **drop/サビ限定**〔既定〕／焚かない／全編（非推奨＝落差が死ぬ） | 打点は歌い出しの語の秒か drop の onset に置く |
| **H2 抜き方** | **暗転**〔既定〕／単色ベタ面へ飛ばす／位置のズレ（registration slam）／ネガ反転／光ワイプ／白フラッシュ | 白フラッシュは連発しない（1秒3回以下）。明るい画では白は効かない＝位置のズレで取る。辞書: flash-cut / negative-invert / light-flood-wipe / zoom-punch / impact-frame |

## 軸に属さない語彙（DIRECTION のカット表に直接書く）
- 繋ぎ: モンタージュ／スマッシュカット／マッチカット／ジャンプカット／グリッチカット／分割画面。
- 時間: スピードランプ／スローモーション／フリーズフレーム／逆再生。
- 選び方は skill `mv-cut-editing`。各語の中身は `direction-library/INDEX.md` の「編集」。
- 場所から考えるなら `direction-library/INDEX.md` の「場面」（場所×光×演出セット）から入り、演出セットの slug で軸の値に落とす。
