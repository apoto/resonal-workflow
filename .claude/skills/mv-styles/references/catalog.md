# MV スタイル・カタログ（13スタイル）

- 選定表を書くときは、この13項目と既定の型 `spectrum-still` を1行ずつ評価する。
- 各スタイルの実装と手順は `styles/<名前>/README.md`。選定表を書く前に `ls styles/` で実物を確かめ、README の「できること／未整備」を読んで工数を見積もる。
- 実験的な資産をそのまま共有している。スタイルごとに手順や作りが揃っていない（歌詞の読み込み方・縦ショートの有無・検査の有無が違う）。「手順が少ない」「未整備」は落選理由にしない。工数は選定表に1行で書く。
- 「向く曲」は雰囲気（静か／明るい／暗い／壮大／切ない／攻撃的 など）を先に、ジャンルは例として書いている。ジャンル名が合わなくても雰囲気が合えば候補に残す。
- 軸の既定は [axes.md](axes.md) の軸コードで書く（書いていない軸は axes.md の〔既定〕）。

## 既定の型（選定表に必ず1行入れる）

### spectrum-still（1枚絵×カメラ割×七色の光）
- 実装: `templates/mv/src/styles/spectrum-still.tsx`。`tools/make_mv.sh` がこれで作る。振り付けは `projects/<slug>/input/song.config.ts`。
- 見た目: 静止画1枚をカメラ割で舐める。被写体の後ろに七色の放射、drop 前に光のトンネル、拍のブルーム、語が弾んで出る字幕、drop の白飛びと暗転。
- 向く曲: 明るい・高揚・疾走。drop がはっきりある曲（hyperpop / future bass / 四つ打ち EDM / 電波、明るいアニソン）。
- 向く歌詞: 多幸・解放・祝祭。
- 軸の既定: L1=下帯・左下 / L3=跳ね出現 / L4=縁＋グロー / C1=静止1枚 / F1=静止画 / F3=区間ごとに差し替え / H2=白飛び→暗転。

## スタイル

### 1. scatter-mincho（散らし明朝＋デジタル崩壊）
- 実装: `styles/scatter-mincho/README.md`
- 見た目: 白い極太明朝を中央を避けて散らし配置。色収差（赤/シアン）＋白い横スメア残像＋赤グロー。サビ/drop で背景に色ズレ、打点で砂嵐ノイズとブラーが一瞬走って収束。静かな展開は暗転。
- 向く曲: 暗い・攻撃的・焦燥・速い。縦ノリで畳みかける曲（DnB / neurofunk / ハードな電子・ロック、激しめのアニソン）。
- 向く歌詞: 暴走・過剰・崩壊・中毒・焦燥。
- 軸の既定: L1=散らし / L2=明朝 / L4=色収差 / C0=出さない / F1=静止画か暗いループ動画 / H2=暗転。

### 2. ring-visualizer（ネオン円形ビジュアライザ／歌詞なし）
- 実装: 静止画の背景 → `styles/ring-visualizer/README.md`／ループ動画の背景 → `styles/ring-visualizer-loop/README.md`（どちらか1つを選ぶ。選定表では1行）。
- 見た目: 被写体を中央に置き、音に反応するネオンの円形波形リングが周りでうねる。歌詞は出さない。
- 向く曲: 浮遊・夜・都会的・クール。歌詞より音を聴かせたい曲、インスト（シンセ / シティポップ / ローファイ / アンビエント寄りの電子）。
- 向く歌詞: 問わない（歌詞は出さない）。
- 軸の既定: L1=出さない / C3=固定バストアップ（中央） / F3=常時うっすら1種 / F4=固定。

### 3. white-cut（白地×中央の黒明朝×ハードカット）
- 実装: `styles/white-cut/README.md`
- 見た目: 白背景に黒の明朝を画面ど真ん中。縦書きが基本で英語のキメだけ横書き。広い字間。拍でハードカット（フェード・重なり無し）、行間に無表示の「間」。キメだけ横波の液状グリッチ（約0.2秒で収束）。
- 向く曲: 静か・洗練・切ない・ミドルテンポ（BPM 90〜115）。デザイン寄りの J-POP / ボカロ、しっとりしたバラード寄りの曲。
- 向く歌詞: 静かな熱・余白・少しの切なさ。
- 軸の既定: L1=中央 / L2=明朝 / L3=ハードカット / C0=出さない / F1=単色 / F3=なし。
- 元になった RESONAL の曲: Heat Shock。

### 4. photocopy-zine（ジン／コラージュ・パンク）
- 実装: `styles/photocopy-zine/README.md`
- 見た目: コピー機のザラつき（紙のグレイン・ハーフトーン網点・コピー劣化）。生成り＋黒＋ビビッドな赤ピンク＋差し色1つ。手描きラフ線画とコラージュのマキシマリズム。高速カットと和欧混植の切り貼りタイポ。
- 向く曲: 明るいのに毒がある・ひねくれ・疾走（BPM 150〜175）。ひねくれポップ / ボカロ / ギターロック寄りの速い曲。
- 向く歌詞: 嘘・偽物・皮肉・不安定さ。ポップな見た目に毒を仕込む。
- 軸の既定: L1=散らし / L3=語単位で入れ替わる / F3=常時うっすら1種（紙のグレイン） / F4=構図ジャンプ。
- 元になった RESONAL の曲: Repeat Offender。

### 5. pink-bounce（ピンク高キー×丸文字×デコ盛り）
- 実装: `styles/pink-bounce/README.md`
- 見た目: ピンク基調の高キー。丸い極太書体に2重フチ（外＝白、内＝濃いピンク）。1文字ずつスプリングで弾んで出て、常に小さく揺れる。ハート・星・キラキラのデコ。キャラはカメラ目線で1枚。
- 向く曲: 明るい・かわいい・多幸感・中〜速テンポ（アイドルポップ / 電波 / 明るいアニソン）。
- 向く歌詞: 自己肯定・ときめき・あざとさ（かわいい×毒も可）。
- 軸の既定: L2=丸ポップ / L3=1文字スプリング / L4=縁＋グロー / C1=表情差分つき静止 / C2=squash&stretch。

### 6. crimson-gothic（黒×赤の退廃ゴシック・明朝＋セリフ）
- 実装: `styles/crimson-gothic/README.md`
- 見た目: 黒×赤。背景は曲ごとの暗い画像。和文＝明朝、英字＝高コントラストのセリフ体。4パターン（左右端の縦書き／中央の巨大1文字／中央の巨大＋色収差／1文字ずつ積んで語にするビルドアップ）をハードカットで切り替え、キメで横波グリッチ。
- 向く曲: 暗い・妖艶・不穏・中〜速テンポ（ダークなボカロ / ゴシック / ダークポップ、ダーク系アニソン）。
- 向く歌詞: 嘘・毒・死・支配。
- 軸の既定: L1=左右の端（縦書き） / L2=明朝 / L3=ハードカット / F1=静止画（暗い） / H2=暗転。

### 7. shape-burst（跳ね出現＋1文字ごとの図形バースト）
- 実装: `styles/shape-burst/README.md`
- 見た目: 極太コンデンスのゴシックが1文字ずつ下から跳ねて出る（オーバーシュート＋バウンド）。1文字＝1図形（□○△◇✕）がはじけて膨張しながら消える。暗い紫×マゼンタ×シアンの発光（高明度のパステルにも振れる）。drop は特大＋色収差ゴースト。
- 向く曲: クール・挑発・ノリが強い・速い縦ノリ（フォンク / トラップ / ハードな電子）。明るく弾む曲にも配色を変えて使える。
- 向く歌詞: 余裕・煽り・夜のアスファルト。
- 軸の既定: L2=極太コンデンス / L3=跳ね出現 / L4=図形バースト / C2=squash&stretch（skill `bounce-rig`）。
- 元になった RESONAL の曲: Cotton Overkill。

### 8. invert-shapes（白いソリッド図形×ネガポジ反転）
- 実装: `styles/invert-shapes/README.md`
- 見た目: 不透明な真っ白の図形（円・三角・四角）の上に極太の角ゴシック。図形に重なった部分だけ文字が黒に反転。暗い紫＋白＋黒の3色だけ。1フレーズ＝1画面のハードカット。図形の配置は不規則に崩す。
- 向く曲: 暗い・攻撃的・不穏・速め〜中速（アングラな電子 / ボカロ / フォンク）。白黒の強コントラストが効く曲。
- 向く歌詞: 挑発・不穏・病みかわいい。
- 軸の既定: L2=極太コンデンス / L3=ハードカット / L4=ネガポジ反転 / H2=ネガ反転。
- 元になった RESONAL の曲: Stutter Step。

### 9. sky-keyvisual（1枚キービジュアル×モーショングラフィックス）
- 実装: `styles/sky-keyvisual/README.md`
- 見た目: 背景（空と雲）・中央のキャラ（浮遊ポーズ固定）・グラフィックの3層。白い太いベクターライン、キャラ背後で回る同心円、斜めに走る破線とインジケーター。展開の変わり目でグラフィックの密度と配置を瞬時に切り替える。キメで「キャラを消して巨大ロゴだけ」「キャラを黒シルエット＋空をグラデに」を1〜数回。
- 向く曲: 明るい・爽快・疾走・抜け感（フューチャーポップ / DnB〜四つ打ち、爽やかなアニソンの OP 系）。
- 向く歌詞: 疾走・浮遊・落下・解放。
- 軸の既定: C1=静止1枚 / C2=浮遊 / F1=キービジュアル1枚固定 / F3=区間ごとに差し替え。
- 元になった RESONAL の曲: Extra Time。

### 10. burn-in（黒地×補色残像の焼きつき）
- 実装: `styles/burn-in/README.md`
- 見た目: 純黒の背景に中央の白文字がハードカット。消えた歌詞が補色（シアン⇄マゼンタ）のゴーストとして同じ位置に焼き残り、減衰しながら積もる。build の末で全停止→ネガ反転→暗転→drop で積もったゴーストを一掃。
- 向く曲: 切ない・壮大・静→爆発の落差が大きい（halftime の melodic dubstep / エモい EDM / 盛り上がるバラード）。
- 向く歌詞: 残像・忘れられない・光の余韻。
- 軸の既定: L1=中央 / L3=語単位で入れ替わる / L4=色収差 / C0=出さない / H2=ネガ反転。
- 注意: 点滅は1秒3回以下。
- 元になった RESONAL の曲: Afterimage。

### 11. lowpoly-corridor（ローポリ3D世界×動くカメラ×立つキャラ）
- 実装: `styles/lowpoly-corridor/README.md`（Remotion＋React Three Fiber）
- 見た目: ローポリの3D世界（発光する石門の回廊・花畑・岩、水辺など題材は差し替え）を仮想カメラがカット割りで駆ける（潜る・回転しながら抜ける・俯瞰旋回・スナップズーム）。透過キャラを3D空間に板で立たせる。ブルーム・色収差・落ちサビだけ光の差す白い世界。
- 向く曲: 壮大・暗い・荘厳・落差が大きい（symphonic / ダークな EDM / ハードコア、壮大なアニソン・劇伴寄り）。
- 向く歌詞: 弔い・毒・退廃・彼岸、または水・空など世界そのもの。
- 軸の既定: F1=3D空間 / F4=構図ジャンプ / C1=透過連番 / C4=fg+bg に割る。
- 元になった RESONAL の曲: Dive Reflex。

### 12. plate-swap（面の切替×静止画プレート×刷り出しゴシック）
- 実装: `styles/plate-swap/README.md`
- 見た目: 面（背景）を数種類だけ持ち、小節頭で丸ごと切り替える（写真的な夜の街／単色ベタ＋ビルのシルエット／単色の高キー面）。被写体は静止画プレートの差し替え（全身1ポーズ＋表情差分＋寄り違い）。極太ゴシックが約0.3秒で刷り出され、約3秒残り、1フレームで一掃。装飾は足さない。
- 向く曲: 夜・クール・静かな熱・中〜速テンポ（シティポップ / ダークポップ / 落ち着いた J-POP）。静と動の落差で持たせる曲。キャラを動かす必要がない曲。
- 向く歌詞: 夜・街・距離・待つこと。断言が1〜2語だけある歌詞。
- 向かない: 全編ハイテンションで緩急が無い曲。長文で説明的な歌詞（文字が溜まる）。
- 軸の既定: L3=刷り出して残す / C1=表情差分つき静止 / C2=呼吸のみ / F1=静止画 / F2=小節頭でswap。
- 実装メモ: 文字の塗りは「地」で決める（暗い面なら明るい単色、明るい面なら黒/灰）。動画生成が要らない＝コストが最小の型。

### 13. portrait-frame（静止立ち絵×切り替わる背景動画×縦書き明朝の積み上げ）
- 実装: `styles/portrait-frame/README.md`
- 見た目: 人は動かず周囲だけが生きている。立ち絵は完全静止（表情差分のみ）、背景が短尺動画で切り替わる。縦書き明朝の歌詞が右から左へ1行ずつ積み上がり、ブロック単位で一気に消える。額縁装飾と暗転での章替え。
- 向く曲: 静か・壮大・叙情。ジャンル非依存（バラード / 劇伴寄り / 速い曲でも可）。背景の切替速度で速さを出す（速い曲ほど面を短く割る）。
- 向く歌詞: 世界そのものが主題（気象・海・空・都市）。キャラが動かないこと自体が態度の曲。
- 軸の既定: L1=右から積む縦書き / L2=明朝 / L3=積み上げ→一掃 / C1=表情差分つき静止 / F1=動画 / F2=セクションごと。
- 実装メモ: 雪・霧・粒子・光条はコード（Remotion）で作る。生成動画はコードで作れない面（面全体の質感が変わるもの）だけに使う。背景動画をピンポンで往復させない。
- 元になった RESONAL の曲: Whiteout。

## カタログの育て方
- 型を確定したら `### N. <name>（短い説明）` を足す（見た目・向く曲（雰囲気＋ジャンル例）・向く歌詞・軸の既定・実装）。
- 実装は `styles/<name>/` に置き、README に手順を書く。曲ごとに変わる色・画像はスタイルのソースに焼き込まない（色はパレット定数1か所、画像は設定から渡す）。
- キャラの動かし方（跳ね・関節・表情差分・切り抜き）はスタイルに焼き込まない＝ skill `bounce-rig` / `puppet-rig` 側に置く。
