# MV カット割り（編集の文法）

カット表＝「区間 → 1カットずつ（被写体・サイズ・長さ・動き・つなぎ）」。規則の出典と数値は [references/grammar.md](references/grammar.md)。

## サイズの記号
`L`＝引き（全景）／`M`＝ミディアム（中継ぎ）／`C`＝寄り（顔・手）／`X`＝超寄り（目・物のディテール）。

## 手順
1. 区間ごとに役割を1行で書く（状況／助走／結論／器楽／落ち／締め）。長さは小節で数え、秒は実測テンポから出す（MV プロジェクトの `input/beats.json`。区間ごとに測るなら MV プロジェクトで `../../tools/py.sh tools/02_estimate_tempo.py`）。
2. 区間ごとに**ベース画**（戻ってくる引きの画）を1つ決める。サビはベース画＋寄りの差し込み（タッチ）で組む。
3. 1カットずつサイズ・長さ・動き・つなぎを決める。下の規則を上から当てる。
4. 点検（レンダー前）: 下の「点検リスト」を全カットに当て、違反は直すか理由を DIRECTION.md に1行書く。MV プロジェクトにカット表の検査スクリプトがあれば（README を見る）それを通す。
5. 各カットの中央フレームを `npx remotion still` で出し、並べて観る（同じ絵が続いていないか・サイズの落差）。
6. 直すときは症状のカットだけでなく、前後2本との並びで直す。

## 並べ順
- 区間の頭は客観→主観（場所の引き → 人 → 寄り）。例外は倒置＝象徴的な寄りから入って引きで明かす。
- 曲の最初のカットは L（マスターショット）か象徴的な寄り。最後は冒頭のマスターショットを同じ構図・別の時間帯で繰り返して閉じる。
- 見せたい被写体はすぐ出さない（留め）。場所・予兆を先に見せる。
- 寄りは段階的に詰め（L→M→C→X）、山の頂点で超寄り。中継ぎを飛ばした L→C は「転換」の合図＝狙うときだけ。
- 嬉しい場面は寄りから、静かな／寂しい場面は引きから入る。
- 主観ショットは短く・特別な瞬間だけ。前に必ず客観で状況を見せる。

## サイズと長さ
- 同じ被写体・同じサイズを続けない（ジャンプ）。サイズを大きく変えるか、間に別の画（ブリッジ）を挟む。
- 引きは長く・寄りは短く（引き 3〜5秒／寄り 1〜3秒）。特別な理由が無ければ1カット5秒以内。
- 同じ長さを並べない（メトロノームになる）。
- 同じ画角は20秒が限界。区間が変わったら構図の型も変える。

## 音楽とカット点
- アップテンポは拍の頭で切る（1フレームもずらさない）。カット点は小節線か拍に吸着させる。
- スローな区間は拍の間でオーバーラップ（0.6〜1.0秒）。アップテンポに長いオーバーラップを使わない。多用しない。
- タッチ＝ソロ・決めの音に1小節の寄りを差す。
- 打点（サビ頭など）は光ワイプ＋頭0.2秒で一気に寄るクラッシュ。打点は区間の頭に限る。
- 歌詞に出た物をそのまま寄りで映さない。その物の周りにある場所・光・気配で想像させる。

## つなぎ
- アクションつなぎは動き出しで切る。方向と速さを前後で揃える。途中を抜くとスピードが出る。
- 形・物・色で前後を繋ぐ（丸→丸、同じ物の受け渡し）。
- イマジナリーラインを越えない（進行方向を前後で揃える）。
- 暗転は区切り（1秒前後）。フェードアウト3秒以内は区切り、5秒以上は終わり。1つの効果に1つの意味だけ持たせる。
- 心象の画は現実の画と見分けがつくように（極端なアングル・傾き・ボケ）。

## 構図・カメラ
- 顔の向き・進行方向の側を空ける（三分割の交点に目）。寄りは頭頂を切り、引きは頭上を空ける。
- 傾き（ダッチ）は1区間2本まで・6〜8度。
- カメラの動きに意味を1つ: 押し＝発見・決意／引き＝喪失・余韻・明かす／ゆっくりのズーム＝覗き見／クラッシュ＝衝撃。
- 横パンは画面幅1つ分に5秒以上かける（速いとちらつく）。速い振りは編集点を隠す用途に限る。
- 前景を端で切って奥行きを3層（前・中・奥）に。
- 明るいハイキーの直後に急なローキーを置かない。

## 点検リスト（レンダー前）
- [ ] 隣り合う2カットが同じ被写体・同じサイズになっていない
- [ ] 5秒を超えるカットに理由がある
- [ ] 同じ長さのカットが3本以上連続していない
- [ ] カット点がすべて拍か小節線に乗っている（アップテンポ区間）
- [ ] 同じ構図が20秒を超えて続いていない
- [ ] 各区間の頭が客観（引き）から入っている、または倒置の理由がある
- [ ] 打点の演出が区間の頭だけにある
