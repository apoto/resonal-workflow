# 編集の文法（要約）


映像編集で一般に知られている考え方を、自分の言葉でまとめたもの。数値は目安。MV への当てはめ（右列）はこのリポジトリの読み替え。

## 1. 音楽にのせる
| 規則 | 値・手順 | カット表 |
|---|---|---|
| アップテンポは拍の頭で切る | 1フレームずれると歯切れが悪い | カット点を小節線に吸着 |
| スローは拍の間で切る・OL | ヨリとヒキが数秒重なる長い OL | オーバーラップ |
| 間隔をばらす | 同間隔が続く＝メトロノーム | 点検リスト「同じ長さ」 |
| ベース画＋タッチ | ベース＝全体の引き。タッチ＝ソロ等で寄りをチラッと | 区間ごとのベース画・1小節の寄り |
| 曲のイメージを壊さない | 映像は曲を助ける | — |

## 2. 並べ順・構成
- ファーストカットは ①マスターショット ②倒置（象徴的アップ→マスター、アバン）③時系列 のどれか。
- 留めとリアクション: 対象をすぐ見せず、期待をためる。リアクションの位置で感情移入が変わる。
- 客観→主観。5W1H を客観で立ててから主観へ。主観・カメラ目線は短く特別な瞬間だけ。
- ワイド→ミディアム→決めだけ MCU/CU→ワイドへ戻す。ミディアムは中継ぎ。中継ぎなしの L→CU は劇的転換として読まれる。
- 寄りは転換・発見直後のリアクション・主観に限る。使いすぎると効かない。
- 段階的に寄って最後にマクロで緊張。逆に正体不明の超アップから引いて明かす。
- 冒頭の印象的な構図を終盤に同じ構図で繰り返すと一巡して閉じる。構図は同じで衣装/色/状況だけ変えて変化を見せる。
- 象徴ショットはシーンの最初か最後に置く。終盤で再利用・変形。抽象ショットは流れを止めるので短く。
- 対立（山と谷）を挟んで構成を動かす。心象の画は極端なアングル・傾き・ボケ・望遠で現実と分ける。

## 3. サイズと長さ
- 同一被写体で同サイズ・同ポジションを続けない＝ジャンプ。微妙な違いは不快、明確な違いはキレ。対処＝サイズを大きく変える／ブリッジングカット（観衆など）を挟む。
- 長さの適量＝その画の役割が終わるまで。特別な意味がなければ5秒を越えない。アップは短く、ロングは長く（表札2秒・家の全景4〜5秒・月2〜3秒）。
- 同じ長さを並べると単調、機械的に変えても駄目（役割で決める）。
- 同じ画角はもっても20秒が限界（インタビューの例）。

## 4. つなぎ
- アクションつなぎは動作の初動（3:7 の位置）で切る。重要な動作は3:7を崩して目立たせる。方向と速さを揃える。二度見せで強調、途中を抜くとスピード。
- 動いているところで切る（止まってから切らない）。フレームイン/アウトは被写体が画面に残っているうちに切る。
- しりとり（A・(A)・(B)・B＝共通要素を持つ画を間に挟む）、形（丸）・物の受け渡し・音・色で繋ぐ。
- イマジナリーラインを越えない。

## 5. トランジション
| 種類 | 長さ | 意味 |
|---|---|---|
| 黒（暗転） | 1〜2秒（シャッター的なら 20f＋音） | 区切り |
| 白 | 10f〜1秒 | 閃き・衝撃 |
| スウィッシュパン | 20f〜1秒 | 場面転換・編集点隠し |
| F.O / F.I | 5秒以上＝場面の終わり／3秒以内＝区切り | — |
| O.L | — | 時間経過・回想 |
- 1つの効果に別の意味を持たせない（使い回さない）。

## 6. 構図・カメラ
- 三分割の交点に目、視線/進行方向側を空ける。視線を向けた被写体を中央に置くと停滞。寄りは頭頂を切る、引きは頭上を空ける。
- 画面内のサイズ＝その瞬間の重要度（映画文法の定石）。意味が明かされない小物を超寄りで見せ後で回収。
- 注意をそらす物はフレームから外す。前景を端で切って視線誘導（ルプソワール）、奥行きは前・中・奥の3層。
- 背景を被写体より暗く（〜2段）、バックライトで分離。キャッチライトを入れる。
- 全編の視覚戦略を一方向の変化にする（ハイ→ロー、手持ち→固定 等）。一度割り当てた構図を別の感情に使い回さない。
- アングルは付けすぎない（アイレベルから少し上下）。ダッチは1シーン数ショットまで、傾きは垂直線で見せる。
- ハイキー→急なローキーにしない。マジックアワーは20〜30分。
- クラッシュズーム＋少しずれたフレーミング＝緊迫。ゆっくりのズーム＝覗き見。
- 横パンは画面幅1つ分に5〜7秒以上、縦ティルトは画面高さ1つ分に2.8秒以上（ちらつき防止）。スウィッシュで編集点を隠す。
- ドリーイン＝発見・決意、ドリーアウト＝喪失・孤独。ドリーズームは速い＝極端な感情、極めてゆっくり＝何かが起きている。
- トラッキングは MS〜LS。横から＝ダイナミック、正面から＝感情移入。クレーンは前景に固定物がないと動きが見えない。
