# 英語詞モード

英語詞・英語パートが多い曲では手順 1 の前に読む。日本語詞との対照としてよく語られる「英語詞はこうだ」を、英語で書く原理としてまとめたもの。
SKILL.md の手順（コンセプト〜改稿）はそのまま使い、差分だけをここに書く。

---

## 1. 頭の切り替え（日本語詞の癖を持ち込まない）

### 1-1. 響き ≧ 内容
- 英語詞＝響き＞内容／日本語詞＝響き＜内容。1行ごとに意味を背負わせる癖を捨てる。
- US＝響き重視、UK＝文学的・言葉遊び。曲のレーン（EDM/ポップ＝US寄り、内省/物語＝UK寄り）でどちらに振るか最初に決める。

### 1-2. 情報量は3〜4倍。詰めずに繰り返す
- 「I love you」3音 vs 「わたしはあなたがすきです」12音。同じ音数で英語は3〜4倍の情報が乗る＝凝縮すると窮屈になる。
- リフレイン（同一フレーズの反復）は英語詞の骨格。フック1行を決めたら繰り返す。
- 1曲で言うことは1つ。Verse＝場面、Pre＝昂り、Chorus＝フックの反復＋最小限の変化。

### 1-3. 感情語のコストが低い
- 直接的な感情語（I love you / I'm done / set me free）はサビで堂々と使ってよい。ただし全員が使う＝それだけでは平凡。差は具体イメージと言い回しの角度で付ける（→ §3-2）。
- Verse＝描写、Chorus＝感情の言い切り、の分業。

---

## 2. 音に乗せる

### 2-1. 1音符＝1音節、強拍＝強勢音節
- 音符数＝音節数で数える（文字数ではない）。行ごとに音節数をメモする。
- 英語は強勢拍リズム。メロの強拍にストレスの乗る音節を置く。"beau-TI-ful" のような強勢ズレは不可。
- 迷ったら単音節語（love / break / night / run / ghost）。どの拍にも乗る。

### 2-2. ロングトーンは開母音
- 伸ばす母音は ah / oh / oo / ay。ee は金属音。
- サビの最高音・伸ばす語尾に open vowel の語を当てる（alone / gold / high / away / tonight / go / show）。ee で終わる語（free / me / see）を伸ばすなら短く切るか「あえて」の自覚を持つ。
- アタックには破裂音・硬い子音（b/d/g/k/p/t）。

### 2-3. Sing like talking
- 書いたら必ず声に出して歌う。
- 縮約形を使う: I am → I'm、cannot → can't、going to → gonna、want to → wanna。フル形は書き言葉。
- 休符で句を区切る。冠詞・前置詞（a / the / of）を強拍に乗せない。

---

## 3. ライム（構造材。飾りではない）

### 3-1. 緩くていい、設計は必須
- day/say 程度の対応でよい。ライム辞典を引くのは標準作業。
- near rhyme / slant rhyme（time/mine、love/enough）は可。完全韻に縛られて意味を犠牲にしない。
- スキーム無しは不可。Verse ごとに AABB / ABAB / AXAX を先に決める。
- ライム逆算法: ①区間の着地語（フック語・タイトル語）を決める → ②韻候補を書き出す → ③各行末に配って間を埋める。
- 強勢音節で踏む（unstressed で踏んでも聞こえない）。

### 3-2. ありきたり回避
- 手垢ペア（fire/desire、heart/apart、night/light、cry/die/why）は1曲に1ペアまで。使うなら片方を near rhyme で外す。
- 差別化は具体名詞・固有の情景／結びつきの薄い2語の合体（"dirty science"）／対比語の衝突。
- フック1行だけは「この曲にしかない言い方」にする（全行凝縮 → 1点凝縮）。

---

## 4. 構成の差分

- サビ＝結論／感情の発散はそのまま。タイトル＝フック行の中に置くのが既定。
- Verse 1 と Verse 2 で場面か時制を変え、Chorus は同一のまま。
- 英語は主語必須＝I→you の関係を1つに固定する（立ち位置が文法レベルで露出する）。
- 3幕構成・冒頭1行・ネガポジ1行は言語非依存＝そのまま適用。

---

## 5. 改稿「音」の視点の英語版チェック項目

SKILL.md 手順 6 の視点（構造→音→言葉）は同じ。「音」だけ以下に差し替える:

1. 全行を声に出して歌う（省略不可）
2. 行ごとの音節数が区間内で揃っているか（±1まで）
3. 強拍に強勢音節が乗っているか（冠詞・前置詞が強拍に来ていないか）
4. ロングトーンが open vowel か（ee を伸ばしていないか）
5. ライムスキームが設計どおりか（無韻の行末の事故／手垢ペアが2つ以上ないか）
6. 縮約形になっているか
7. 不自然な英語がないか（冠詞の抜け・単複・コロケーション）。歌詞的破格は「あえて」の自覚があるものだけ
8. リフレインが機能しているか（繰り返しを恐れて毎行変えていないか）

## 6. このリポジトリでの適用

- 一人称は I。歌い手の人格（profile/character.md・CLAUDE.md の人格節）は言語が変わっても同じ。
- 「歌詞（Suno用）」は表示用と同じでよい。固有名詞・造語の発音誤りが出るときだけ、スペルを発音寄りにする。
- 間奏・ドロップに歌詞行を書かない（SKILL.md「歌詞（Suno用）の書き方」）。
- LYRICS.md の「メロディ・譜割りメモ」に音節数・強勢・ライムスキームを書く。改稿ログにライムの変更も残す。

## 7. アンチパターン（英語詞専用）

1. 全行に情報を詰める／リフレインを避ける
2. 音節数を文字数で数える／強勢無視で音符に流し込む
3. ライムスキーム無しで書き切る
4. 完全韻に縛られて意味を壊す
5. フル形・書き言葉（I am / cannot / going to）のまま歌わせる
6. 手垢ペアを複数使う
7. ee 母音のロングトーン（無自覚なら事故）
8. 声に出さずに納品する
