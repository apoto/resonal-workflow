# 作詞

一発書きにしない。下書き（v1）を書いてから、視点を変えて読み直して直す。

## 読むもの
- `songs/<曲フォルダ>/BRIEF.md`（コンセプト・曲構成・歌詞への申し送り）
- profile/character.md（歌い手の一人称・話し方）と profile/lyrics.md（言語・作風のこだわり・使わない言葉）
- 技法の要約 `references/craft.md`（改稿の締めに §5 のチェックリストを通す）
- 英語詞・英語パートが多い曲は `references/english-lyrics.md`

## 原則
1. 感情は説明せず描写する。感情の名前より、その感情がにじむ物・行動・情景を置く。
2. 具体物で立たせる。その歌い手にしか言えない具体的な名詞を最低数個。
3. サビは結論（感情の言い切り）。物語を進めるのは A・B。サビに状況説明を混ぜない。
4. 歌えない行は失格。全行を声に出して確かめる（母音・音数・強拍）。
5. ベタな語・既視感のあるサビを1つ意図的に外す。
6. 歌詞は耳で一度聴いて通る平易さで書く。凝るのはタイトル。
7. 同じことを言い換え続けない。メッセージは1点に置き、そこへ至る情景を書く。

## 作風の選択肢（profile/lyrics.md に書かれていれば従う）
profile/lyrics.md に指定がある作風だけを適用する。書かれていなければ使わなくてよい。例:
- **営み × 装置**: 主題は人の営み（引っ越し・通勤・卒業…）、語彙は別の領域（天気予報・棚卸し・時刻表…）から取る。
- **指示語を使わない**: 「それ・あれ・ここ・そっち」を具体の名詞に置き換え、誰が読んでも同じ絵になるようにする。
- **判定語を使わない**: 「勝ち・負け・正解・無敵」のような態度の宣言を書かず、振る舞いの具体で見せる。
- **二人称を出さない**: 「君・あなた」を出さず、歌い手の視点だけで書く。
- **語の使い回しを制限する**: サビ以外で同じ内容語は2回まで。
- **使わない言葉・一人称の回数**: profile/lyrics.md の一覧どおりに守り、書いた後に数える。

## 手順

### 1. コンセプトを言語化する（各1〜2行）
- 一行コンセプト / 語り手・場面・時間帯・立ち位置（物語のどの地点で歌っているか）
- 素材の名詞 5〜10 個（予定調和な語を1つ外す）
- サビのフック候補 2〜3 案と、タイトルを置く位置

### 2. 裏設定を決める（歌詞に全部は出さない）
1行で言い切る。「〜かも」は未決と同じ。
- 歌い手は誰で、誰に（または何に）向けて歌っているか
- 曲が始まる直前に何が起きたか
- 冒頭で最初に見えている物
- サビで言い切る気持ちを1行で
- いちばん強くしたい行はどこか

### 3. 物語を短く書いてから削る
- 曲の場面を小説のように 800〜1500 字で書く（音・匂い・手の動きまで）。曲フォルダの STORY.md に保存する。
- 削れない文に印を付け、A＝状況 / B＝助走 / サビ＝結論 に割り当て、音数に合わせて削る。残すのは物と行為、削るのは説明と感情の名前。
- 全行について「物語のどの文から来たか」を言えるようにする。

### 4. 構成を決める
- BRIEF.md の曲構成に従う。無ければ A / B / サビ / 2番 / 落ちサビ / ラスサビ を基本に取捨する。
- イントロに語り・タイトル連呼を置かない。歌い出しから歌う。
- 冒頭1行に一番時間をかける（場面と気持ちが同時に立つか）。

### 5. 下書き（v1）を通しで書く
- 毎行声に出す。ロングトーンは開く母音（ア・オ・ウ）、強拍に破裂音・濁音。
- 1拍に2音・撥音・促音で詰めてリズムを作る。休符をまたいで単語を切らない。
- 明るい曲に暗い1行（または逆）を1か所だけ置く。
- 磨き込まずに最後まで書き切る。

### 6. 改稿（3つの視点で1周）
書いた頭のまま読まない。視点を1つずつ切り替え、各視点で指摘を3件以上出してから直す。

| 視点 | 見ること |
|---|---|
| 構造 | コンセプトが一言で言えるか／1番と2番で立ち位置がぶれていないか／サビが結論になっているか／冒頭1行の強さ |
| 音 | 全行を声に出す／音数とリズム／ロングトーンの母音／韻が母音だけの偽物になっていないか／語尾の単調さ |
| 言葉 | 内容語・一人称・二人称の出現回数を数える（`grep -o` などで機械的に）／説明している行／ベタな語／profile/lyrics.md の決まりに反していないか |

- 指摘は「該当行 → 何が問題か → 直し案」の3点で書く。採用しない指摘も理由を1行残す。
- 1周したら `references/craft.md` §5 のチェックリストを通す。構造の作り直しが要るときだけ2周目に入る。3周目に入る前は利用者に確認する。
- 直しが行ったり来たりしたら両案を並べて利用者に選んでもらう。

### 7. LYRICS.md を書く
`songs/<曲フォルダ>/LYRICS.md` に下のテンプレで書く。見出しの語は変えない（`./next.sh` と MV のスクリプトが見出しで読む）。書いたら `./next.sh` を実行する。

## LYRICS.md テンプレ
```markdown
# <Title>

## コンセプト
- 一行コンセプト / 語り手・場面 / 素材の名詞

## 歌詞（表示用）
[Verse 1]
<漢字かな交じりの本来の歌詞。1行＝画面に出す1フレーズ>

[Chorus]
...

## 歌詞（Suno用）
[Verse 1]
<表示用と行・内容が完全に同じで、読みだけを変えた版>

[Chorus]
...
[End]

## メロディ・譜割りメモ
- ブロックごとの音数感・伸ばす語・BPM 目安

## 改稿ログ
- v1 → v2: <該当行> を <理由> で <こう直した>
- 不採用: <指摘> → <理由>
```

### 「歌詞（Suno用）」の書き方
- 日本語は漢字をひらがな・カタカナに開く（読み違い防止）。英語はそのまま。行と内容は表示用と完全に一致させる。
- 英語だけの曲は表示用と同じでよい。造語・固有名詞は発音に寄せた綴りにしてよい。
- セクション名は `[Verse 1]` `[Pre-Chorus]` `[Chorus]` `[Bridge]` のように角かっこで書く。末尾は `[End]`。
- 間奏・ドロップは歌詞行を書かず、`[Instrumental]` のような角かっこの指示だけにする（歌詞行を書くと読み上げられる）。
- 歌う部分の合計が2分を切ると器楽で水増しされやすい。短い曲は2番やラスサビで歌う量を確保する。

## 既存の歌詞の添削
「この歌詞を見て」「添削して」と渡されたときは、手順 2 の問いを歌詞に当てて答えられない所（裏設定の穴）を出し、次に手順 6 の3視点で指摘する。音源が完成している曲の LYRICS.md を利用者の了承なしに書き換えない。

## 守ること
- 実在の曲の歌詞・特徴的なフレーズを再現しない。「〜風」は手法と語感の参考に留める。
- 実在の人物の発言として歌詞を作らない。
